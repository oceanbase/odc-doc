# Use Web ODC

This topic describes some basic operations for using Web ODC.

## Create a user

Example: Create a user named `ODCUSER1` in OceanBase Developer Center (ODC) as the administrator and grant the permissions of the `system_admin` role to the user.

1. Log in to Web ODC. In the left-side navigation pane of the project collaboration window, choose **<UI-TERM key="odc.page.Auth.UserPermissions">User Permissions</UI-TERM>** > **<UI-TERM key="odc.page.Auth.User">Users</UI-TERM>**. On the **<UI-TERM key="odc.components.FormResourceSelector.const.User">Users</UI-TERM>** tab, click **<UI-TERM key="odc.components.UserPage.CreateUser">Create User</UI-TERM>**.

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/quickstart/webodc/using%20odc/1-EN.png)

2. On the **<UI-TERM key="odc.components.UserPage.CreateUser">Create User</UI-TERM>** page, complete the user and role settings.

    ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/quickstart/webodc/using%20odc/2.0-EN.png)

    This parameter is optional. You can assign multiple roles to a user. Click the field. In the drop-down list, select the roles that you want to assign to all users that you have created. If no role is available, go to the **<UI-TERM key="odc.components.RolePage.CreateARole">Create Role</UI-TERM>** page to create one.

3. Click **<UI-TERM key="src.component.Task.LogicDatabaseAsyncTask.CreateModal.12C8523B">Create</UI-TERM>**.

## Create a data source

### Create an OceanBase data source

Example: Create an OceanBase MySQL data source in ODC.

| Parameter | Example value |
| --- | --- |
| Data source name | mysql4.2.0 |
| Host IP address | xxx.x.x.x |
| Port number | 8080 |
| Cluster name | odc_cluster |
| Tenant name | mysql_tenant |
| Database username | odc |
| Database password | ****** |
| sys tenant account | test |
| sys tenant password | ****** |

1. Obtain the connection information or connection string of the data source instance. The connection string is in the format of `mysql -h host name -P port number -u database username@tenant name#cluster name -D default database -p ' database password'`. Here is an example:

    ```shell
    -hxxx.x.x.x -P8080 -uodc@mysql_tenant#odc_cluster -Dodc -p'******'
    ```

2. In the left-side navigation pane of the project collaboration window, choose **<UI-TERM key="odc.SpaceContainer.Sider.DataSource">Data Sources</UI-TERM>** > **<UI-TERM key="odc.Datasource.NewDatasourceDrawer.NewButton.CreateADataSource">Create Data Source</UI-TERM>** > **<UI-TERM>OceanBase MySQL</UI-TERM>**.

    ODC supports the following OceanBase Database instance types:

    * **<UI-TERM>OceanBase MySQL</UI-TERM>** or **<UI-TERM>OceanBase Oracle</UI-TERM>**: a database instance that you build in your own environment.

    * **<UI-TERM>OB Cloud MySQL</UI-TERM>** or **<UI-TERM>OB Cloud Oracle</UI-TERM>**: a database instance on Alibaba Cloud.

    ![datasource1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/430/300.quickstart/200.web-odc-quickstart/300.quickstart-using-web-odc/datasource1EN.png)
