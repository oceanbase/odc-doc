# Install Client ODC

This topic describes how to install the Client ODC on different operating systems.

## Background

In personal development scenarios, you can also use the Client ODC. The Client ODC supports Windows and MacOS operating systems. Compared with Web ODC, the Client ODC provides only the complete features related to SQL development, and does not support control and collaboration features.

## Install Client ODC

### Windows

1. [Download the Client ODC](https://en.oceanbase.com/softwarecenter).

2. Double-click the installation file you downloaded to start the installation.

3. After the installation wizard starts, select an installation path and click **Install**.

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/quickstart/clientodc/install/1-EN.png)

4. After the installation is completed, start the Client ODC.

    ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/quickstart/clientodc/install/2-EN.png)
   <main id="notice" type="explain">
     <h4>Note</h4>
     <p>The program checks the environment when it starts. If the environment does not meet the requirements, an error message is displayed, prompting you to continue to start the application or close the process and repair the environment. If the environment meets the requirements, the application starts normally. You can then log in to the Client ODC and create a data source. </p>
   </main>
 </main>

### MacOS

1. [Download the Client ODC](https://en.oceanbase.com/softwarecenter).

2. Drag **OceanBase Developer Center** to **Applications**.

    ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/quickstart/clientodc/install/3.0.png)

3. After the installation is completed, start the Client ODC.

    ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/quickstart/clientodc/install/2-EN.png)
