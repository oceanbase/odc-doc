# Global variable management

This topic provides information on managing global variables.

## Background information

A global variable is a database variable for global management and control of a database.

On the **<UI-TERM key="odc.SideBar.Manager.GlobalVariables">Global Variables</UI-TERM>** page of ODC, you can query and modify all database variables for the current data source.

## Query global variables

Assume that you want to query database variables of the data source `mysql420` in the SQL development window.

1. In the left-side navigation pane, choose **<UI-TERM key="odc.Workspace.ActivityBar.type.OMManagement">O&M Management</UI-TERM>** > **<UI-TERM key="src.component.WindowManager.2A36DA18">Global Variables</UI-TERM>**.

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/connection-management/global-variables-en.png)

2. Select the data source `mysql420` and click **<UI-TERM key="src.component.Task.MutipleAsyncTask.components.Template.AB6525D4">OK</UI-TERM>**.

    ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/quickstart/webodc/using%20odc/5-EN.png)

3. On the **<UI-TERM key="src.component.WindowManager.2A36DA18">Global Variables</UI-TERM>** page, you can query all database variables of the data source `mysql420`.

    ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/connection-management/view-en.png)

## Edit global variables

Assume that you want to modify the value of the database variable `connect_timeout` for the data source `mysql420` in the SQL development window.

1. Search for the connect_timeout database in the search field.

    ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/connection-management/connect-timeout-en.png)

2. In the **Session Attributes** list, click the variable name `connect_timeout` and then click the **<UI-TERM key="odc.components.ShowTableBaseInfoForm.Editing">Edit</UI-TERM>** button to change the value to `20`.

    ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/connection-management/edit-en.png)

3. In the **<UI-TERM key="workspace.window.session.modal.sql.title">SQL Confirmation</UI-TERM>** dialog box, modify and confirm the SQL statement and click **<UI-TERM key="odc.TaskManagePage.component.TaskTools.Run">Execute</UI-TERM>**.

    ![6](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/connection-management/confirm-en.png)

4. In the **<UI-TERM>Session Attributes</UI-TERM>** list, you can view the new value of the `connect_timeout` variable.
