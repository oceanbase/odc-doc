# Data sources and project collaboration

## Background information

After the project administrator creates a project member, the project member can create a data source and add a database in the data source to the project to perform database change tasks.

![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/422/400.connection-management/200.personal-connection-and-project-collaboration/1EN.png)

1. The system administrator creates a project in Web OceanBase Developer Center (ODC) and assigns members to the project.

2. The system administrator or a project member with the data source creation permission creates a data source.

3. The project DBA or project owner adds a database in the data source to the project.

4. A project member creates a database change task.

5. When the project member initiates a task ticket, an approval process is automatically selected based on the risk level and identification rules.

6. The approval roles on the corresponding approval process nodes review the task process.

7. The database change task is executed after it is approved.

### Edit a data source

Click **<UI-TERM key="odc.components.ScriptManageModal.columns.Edit">Edit</UI-TERM>** in the **<UI-TERM key="odc.component.CommonDetailModal.TaskProgress.Operation">Actions</UI-TERM>** column of the target data source. The **<UI-TERM key="odc.Datasource.NewDatasourceDrawer.EditDataSource">Edit Data Source</UI-TERM>** panel appears, which shows the configuration information of the current data source in a similar way as the **<UI-TERM key="odc.Datasource.NewDatasourceDrawer.CreateADataSource">Create Data Source</UI-TERM>** panel. You can modify the settings in the **<UI-TERM key="odc.Datasource.NewDatasourceDrawer.EditDataSource">Edit Data Source</UI-TERM>** panel.

Before you change **<UI-TERM key="odc.AddConnectionForm.Account.PrivateAccount.DatabasePassword">Database Password</UI-TERM>**, you must first click **<UI-TERM key="odc.component.GlobalHeader.ChangePassword">Change Password</UI-TERM>** next to the password box. You can click **<UI-TERM key="odc.SSO.NewSSODrawerButton.Edit.Cancel">Cancel</UI-TERM>** next to the password box to abort the operation. Then, the content before the modification is restored in the password box.

### Clone a data source

1. Click **<UI-TERM key="odc.src.page.Workspace.SideBar.ResourceTree.SelectPanel.Datasource.Clone">Clone</UI-TERM>** in the **<UI-TERM key="src.page.Workspace.components.SQLResultSet.F84FA469">Actions</UI-TERM>** column of the target data source to go to the **<UI-TERM key="odc.Datasource.NewDatasourceDrawer.NewButton.CreateADataSource">Create Data Source</UI-TERM>** panel.

2. In the **<UI-TERM key="odc.Datasource.NewDatasourceDrawer.CreateADataSource">Create Data Source</UI-TERM>** panel, the configuration information of the data source is automatically populated to quickly create a cloned data source.

### Delete a data source

If a database connected to a data source no longer exists or is no longer required, you can delete the current connection configuration.

To delete the current connection configuration, click **<UI-TERM key="src.page.Project.Notification.components.B65E55FA">Delete</UI-TERM>** in the **<UI-TERM key="odc.components.PLDebugResultSet.Operation">Actions</UI-TERM>** column of the target data source.
