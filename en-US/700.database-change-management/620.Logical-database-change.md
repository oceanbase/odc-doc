# Logical database change management

## Background information

ODC V4.3.2 and later versions support making changes to data in logical databases. You can run time-consuming SQL statements through a logical database change task to avoid statement execution timeout.

<main id="notice" type='explain'>
   <h4>Note</h4>
   <ul>
   <li>If you do not have logical database permissions, you can apply for them via <strong>Apply for Database Permissions</strong> in the project/task menu.</li>
   <li>For information on logical databases and physical databases, see <a href="200.project-collaborative-management.md">Logical Database Management</a>.</li>
   </ul>
</main>

## Considerations

- Only OceanBase MySQL and MySQL data sources are supported.

- Only DDL changes are supported.

- SQL check specifications and SQL window specifications in the ODC security guidelines are not supported.

## View a logical database change task

### Task information

1. In the logical database change list on the **<UI-TERM key="src.component.Task.component.ImportModal.7C3EB72C">Ticket</UI-TERM>** page, click the **<UI-TERM key="src.component.Task.component.PartitionPolicyTable.BF0C419E">View</UI-TERM>** button under the Actions column.

2. In the pop-up task details panel, click the **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskInformation">Basic Information</UI-TERM>** tab to view information such as the target logical database, task type, risk level, and SQL content.

3. Click **<UI-TERM key="odc.TaskManagePage.component.TaskTools.InitiateAgain">Initiate Again</UI-TERM>** to re-initiate the logical database change task.

    <!-- <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/432/700.database-change-management/620.logical-database-change/5.png" width="900"> -->

### Task process

In the task details panel, click the **Task Process** tab to view information such as the task initiation status, approval status, execution status, and execution result.

<!-- <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/432/700.database-change-management/620.logical-database-change/6.png" width="900"> -->

### Execution records

In the task details panel, click the **Execution Records** tab to view the task execution status.

### Task logs

In the task details panel, click the **Task Logs** tab to view all logs and alert logs of the task.

<!-- <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/432/700.database-change-management/620.logical-database-change/7.png" width="900"> -->

| Information Item | Description |
| --------- | -------------- |
| All Logs | All logs display comprehensive information such as **INFO**, **ERROR**, and **WARN** logs for the task. You can click the **Find**, **Download**, and **Copy** buttons to search for information, download, or copy all log information. |
| Alert Log | The alert log displays only the **ERROR** and **WARN** logs of a task. When a task fails, you can view the error information in the alert log. You can click the **Find**, **Download**, and **Copy** buttons to search for information, download, or copy the alert log. |
