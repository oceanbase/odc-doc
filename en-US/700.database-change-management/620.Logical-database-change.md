# Logical database change management

## Background information

ODC V4.3.2 and later versions support making changes to data in logical databases. You can run time-consuming SQL statements through a logical database change task to avoid statement execution timeout.

<main id="notice" type='explain'>
   <h4>Note</h4>
   <ul>
   <li>If you do not have logical database permissions, you can apply for them via <strong>Apply for Database Permissions</strong> in the project/ticket section.</li>
   <li>For information on logical databases and physical databases, see <a href="200.project-collaborative-management.md">Logical Database Management</a>.</li>
   </ul>
</main>

## Considerations

- Only OceanBase MySQL and MySQL data sources are supported.

- Only DDL changes are supported.

- SQL check specifications and SQL window specifications in ODC security guidelines are not supported.

## View a logical database change task

### Task information

1. In the logical database change list on the **<UI-TERM key="odc.src.page.Workspace.ActivityBar.WorkOrder">Ticket</UI-TERM>** page, as shown above, click the **<UI-TERM key="odc.Secure.MaskingAlgorithm.View">View</UI-TERM>** button under the Actions column for the task you want to view.

2. In the task details panel that appears, click the **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskInformation">Basic Information</UI-TERM>** tab to view information such as the logical database, task type, risk level, and SQL content.

3. Click **<UI-TERM key="odc.TaskManagePage.component.TaskTools.InitiateAgain">Initiate Again</UI-TERM>** to re-initiate the logical database change task.

    <!-- <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/432/700.database-change-management/620.logical-database-change/5.png" width="900"> -->

### Task process

In the task details panel, click the **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskFlow">Workflow</UI-TERM>** tab to view information such as the task initiation status, approval status, execution status, and execution result.

<!-- <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/432/700.database-change-management/620.logical-database-change/6.png" width="900"> -->

### Execution records

In the task details panel, click the **<UI-TERM key="odc.component.CommonTaskDetailModal.ExecutionRecord">Execution Records</UI-TERM>** tab to view the task execution status.

### Task logs

In the task details panel, click the **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskLog">Logs</UI-TERM>** tab to view all logs and alert logs of the task.

<!-- <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/432/700.database-change-management/620.logical-database-change/7.png" width="900"> -->

| Information Item | Description |
| --------- | -------------- |
| All Logs | All logs display the full information of tasks, including **<UI-TERM>INFO</UI-TERM>**, **<UI-TERM>ERROR</UI-TERM>**, and **<UI-TERM>WARN</UI-TERM>** logs. You can click the **<UI-TERM key="workspace.window.sql.button.search">Find</UI-TERM>**, **<UI-TERM key="odc.EditorToolBar.actions.script.Download">Download</UI-TERM>**, or **<UI-TERM key="odc.component.Log.Copy">Copy</UI-TERM>** button to search for information, download, or copy all log information. |
| Alert Log | The alert log displays only the **<UI-TERM>ERROR</UI-TERM>** and **<UI-TERM>WARN</UI-TERM>** logs of a task. When a task fails, you can view the error information in the alert log. Click the **<UI-TERM key="workspace.window.sql.button.search">Find</UI-TERM>**, **<UI-TERM key="odc.components.TriggerPage.Download">Download</UI-TERM>**, or **<UI-TERM key="odc.components.ConnectionCardList.Copy">Copy</UI-TERM>** button to search for information, download, or copy the alert log. |
