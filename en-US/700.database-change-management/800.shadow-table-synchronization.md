# Synchronize shadow tables

This topic introduces how to create and view shadow table synchronization tasks in ODC.

## Background information

The shadow table synchronization feature of OceanBase Developer Center (ODC) allows you to automatically create a shadow table in the current database based on the schema of the source table. The shadow table name is the combination of the source table name and a prefix or suffix. This feature applies to scenarios like end-to-end stress testing.

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul>
  <li>The shadow table synchronization feature of ODC V4.0.0 and later supports only the MySQL mode. If the source table contains subpartitions, only HASH/KEY subpartitions are supported. </li>
  <li>After a shadow table is created, you can view it on the Table page. </li>
  <li>When a shadow table is created, if a table with the same name but a different schema already exists, a synchronization SQL statement is generated to update the schema of the existing shadow table. </li>
  </ul>
</main>


## Create a shadow table synchronization task

Assume that you want to create a shadow table named `employee_t` in the `odc_test` database under the `mysql410` data source.

| Parameter | Example |
| ------ | ------ |
| Data Source | mysql4.2.0 |
| Database Name | odc_test |
| Source Table Name | employee |
| Shadow Table Name | employee_t |

1. On the **<UI-TERM key="odc.SideBar.Task.Ticket">Ticket</UI-TERM>** tab in the SQL development window, choose **<UI-TERM key="odc.component.DetailModal.shadowSync.ShadowTableSynchronization">Synchronize Shadow Table</UI-TERM>** > **<UI-TERM key="odc.components.CreateShadowSyncModal.CreateAShadowTableSynchronization">Create Shadow Table Synchronization Project</UI-TERM>**.


2. On the **<UI-TERM key="odc.components.CreateShadowSyncModal.CreateAShadowTableSynchronization">Create Shadow Table Synchronization Project</UI-TERM>** panel, specify the following information.

   1. Select a synchronization object.

      

      | **Parameter** | **Description** |
      |---------|------------|
      | Database | The database to which the shadow table to be created belongs. You can view the name of the current data source.  |
      | Synchronization Range | The table to be synchronized.<ul> <li> **<UI-TERM key="odc.CreateShadowSyncModal.SelectPanel.PartialTable">Partial Tables</UI-TERM>**: Shadow tables will be created in the current database for the selected tables. You can also check the **<UI-TERM key="src.component.BatchSelectionPopover.080F782E">Select All</UI-TERM>** box on the left of the search box to select all source tables.  </li><li>  **<UI-TERM key="src.component.Task.StructureComparisonTask.CreateModal.9C98407E">All Tables</UI-TERM>**: Shadow tables will be created in the current database for all tables in the source database.  </li></ul> |
      | Name of Shadow Table | The name of the shadow table, in the format of **<UI-TERM>prefix</UI-TERM>** + source table name or source table name + **<UI-TERM>suffix</UI-TERM>**. You can use a custom prefix or suffix.  |
      | Synchronization Objects | The source tables to be synchronized as shadow tables. You must specify this field when **<UI-TERM>Synchronization Range</UI-TERM>** is set to **<UI-TERM key="odc.CreateShadowSyncModal.SelectPanel.PartialTable">Partial Tables</UI-TERM>**.  |

   2. Click **<UI-TERM key="odc.component.VersionModal.Next">Next</UI-TERM>** to analyze the structure of the shadow table.


      | **Parameter** | **Description** |
      |---------|-----------------|
      | Synchronized Tables | The **<UI-TERM key="odc.StructConfigPanel.StructAnalysisResult.SynchronizedTables">Synchronized Tables</UI-TERM>** tab displays the source table name, shadow table name, and analysis result. You can click **<UI-TERM key="src.component.Task.component.CommonDetailModal.593D5BD8">View</UI-TERM>** to view the source table schema, shadow table schema, and schema change SQL statement, or click **<UI-TERM key="src.component.Task.component.CommonDetailModal.88502ED7">Skip</UI-TERM>**, indicating that this shadow table is not synchronized.  |
      | Unsynchronized Tables | The **<UI-TERM key="odc.StructConfigPanel.StructAnalysisResult.UnsynchronizedTables">Unsynchronized Tables</UI-TERM>** tab displays the source table name, shadow table name, and analysis result. You can click **<UI-TERM key="odc.StructConfigPanel.StructAnalysisResult.column.CancelSkip">Undo Skip</UI-TERM>** to synchronize this shadow table. <main id="notice" type='explain'><h4>Note</h4><p>A skipped table will be displayed on the **<UI-TERM key="odc.StructConfigPanel.StructAnalysisResult.UnsynchronizedTables">Unsynchronized Tables</UI-TERM>** tab. </br>If a shadow table with the same name and the same schema as the source table already exists, schema synchronization will be skipped. </p></main> |
      | SQL Preview | The SQL statement for schema synchronization.  |
      | Task Settings | <ul><li>Options of **<UI-TERM key="odc.DataArchiveTask.CreateModal.ExecutionMethod">Execution Mode</UI-TERM>** include: <ul><li> **<UI-TERM key="odc.components.TaskManagePage.ExecuteNow">Execute Immediately</UI-TERM>**: The synchronization task is executed immediately.  </li><li> **<UI-TERM key="odc.components.TaskManagePage.ScheduledExecution">Execute On Schedule</UI-TERM>**: The synchronization task is executed on schedule. </li></ul></li><li> Options of **<UI-TERM key="odc.components.CreateAsyncTaskModal.TaskErrorHandling">Task Error Handling Method</UI-TERM>** include: <ul><li> **<UI-TERM key="odc.component.DetailModal.sqlPlan.StopATask">Abort Task</UI-TERM>**: If an error occurs during the execution of the synchronization task, the subsequent SQL scripts are interrupted and no longer executed.  </li><li> **<UI-TERM key="src.component.Task.2DA054B9">Ignore Error and Continue</UI-TERM>**: If an error occurs during the execution of the synchronization task, the SQL script with the error is skipped, but subsequent SQL scripts will be executed. </li></ul></li></ul> |
      | Description | The business background of the project, such as the change purpose and expected goal.  |

3. After you specify the preceding information, click **<UI-TERM key="odc.components.PartitionDrawer.Submit">Submit</UI-TERM>** in the lower-right corner of the panel.

4. After a task is generated, the **<UI-TERM>Tasks</UI-TERM>** panel appears. In the **<UI-TERM>Task</UI-TERM>** panel, you can view the approval status and information about the task.


## View shadow table synchronization tasks

### Task information

1. In the shadow table synchronization list on the **<UI-TERM>Tasks</UI-TERM>** page, click **<UI-TERM key="odc.Secure.MaskingAlgorithm.View">View</UI-TERM>** in the **<UI-TERM key="odc.component.RecordPopover.components.Actions">Actions</UI-TERM>** column.

2. In the **<UI-TERM>Task Details</UI-TERM>** panel, click the **<UI-TERM>Task Information</UI-TERM>** tab to view the basic information and settings of the task.

3. In the **<UI-TERM>Task Details</UI-TERM>** panel, click **<UI-TERM key="src.component.Task.component.ActionBar.C324AD20">Initiate Again</UI-TERM>** in the lower-right corner to initiate the task again.

### Task process

1. In the **<UI-TERM>Task Details</UI-TERM>** panel, click the **<UI-TERM key="odc.components.RecordPage.TaskFlow">Task Process</UI-TERM>** tab to view **Initiated Task Status**, **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskOperationRecord.ApprovalStatus">Approval Status</UI-TERM>**, **<UI-TERM key="src.component.Task.component.CommonDetailModal.CA18955A">Execution Status</UI-TERM>**, and **<UI-TERM>Completion Result</UI-TERM>**.

2. You can click **<UI-TERM key="odc.TaskManagePage.component.TaskTools.InitiateAgain">Initiate Again</UI-TERM>** in the lower-right corner of the panel to initiate the task again.

### Task logs

1. In the **<UI-TERM>Task Details</UI-TERM>** panel, click the **<UI-TERM>Task Logs</UI-TERM>** tab and view all logs and alert logs of the task.

   | Parameter | Description |
   |------|-----------------------------------------------------------------------------------------------------------------------------|
   | All Logs | Displays the complete information of all task logs, including **<UI-TERM>INFO</UI-TERM>**, **<UI-TERM>ERROR</UI-TERM>**, and **<UI-TERM>WARN</UI-TERM>** logs. <br>You can click **<UI-TERM key="src.page.Workspace.SideBar.ResourceTree.DatabaseSearch.86200ED0">Search</UI-TERM>**, **<UI-TERM key="odc.TreeNodeMenu.config.sequence.Download">Download</UI-TERM>**, or **<UI-TERM key="odc.components.ConnectionCardList.Copy">Copy</UI-TERM>** to search for, download, or copy all logs.  |
   | Alert Logs | Displays the **<UI-TERM>ERROR</UI-TERM>** and **<UI-TERM>WARN</UI-TERM>** logs of the task. When a task fails, you can view the error message in the alert logs. <br>You can click **<UI-TERM key="src.page.Workspace.SideBar.ResourceTree.DatabaseSearch.86200ED0">Search</UI-TERM>**, **<UI-TERM key="odc.components.TypePage.Download">Download</UI-TERM>**, or **<UI-TERM key="odc.Script.Snippet.Copy">Copy</UI-TERM>** to search for, download, or copy alert logs.  |


2. You can click **<UI-TERM key="odc.TaskManagePage.component.TaskTools.InitiateAgain">Initiate Again</UI-TERM>** to initiate the task again.
