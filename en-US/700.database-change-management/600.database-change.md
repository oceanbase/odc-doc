# Database change management

## Background information

OceanBase Developer Center (ODC) allows you to change the data in your database. You can create a database change task to run time-consuming SQL statements to avoid an execution timeout.

## Considerations

- A rollback statement can be automatically generated only for the `UPDATE` and `DELETE` statements.

- A change task is allowed to affect a maximum of 1 million rows. If the number of affected rows exceeds 1 million, a rollback statement cannot be automatically generated for this change task.

- If the table contains LOB fields, a rollback statement cannot be automatically generated.

- If the table does not have a primary or unique key when the data source is an OceanBase MySQL or a MySQL data source, a rollback statement cannot be automatically generated.

- If the `SET` and `WHERE` clauses in an `UPDATE` statement are the same, a rollback statement cannot be automatically generated.

- The maximum size of a rollback script that is automatically generated is 256 MB.

## Create a database change task

Example: Change the value of name in the employee table in the odc_test database from xiaoguo to xiaofeng.

| Parameter | Example value |
| ------ | ------ |
| Project name | odc_4.2.0 |
| Data source | mysql420 |
| Database name | odc_test |
| Table name | employee |

1. Choose **<UI-TERM key="odc.SpaceContainer.Sider.Project">Projects</UI-TERM>** > **<UI-TERM key="odc.Project.Project.AllProjects">All Projects</UI-TERM>**. On the tab that appears, click the project name **<UI-TERM>odc_4.2.0</UI-TERM>**.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/600.database-change/1EN.png)

2. On the **<UI-TERM key="odc.page.Project.Ticket">Tickets</UI-TERM>** tab, choose **<UI-TERM key="odc.PermissionApplication.CreateModal.DatabaseChanges">Database Change</UI-TERM>** > **<UI-TERM>Create New</UI-TERM>**.

   ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/600.database-change/2EN.png)

3. In the **Create Database Change Task** panel, configure the following parameters.

   ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/600.database-change/3EN.png)

   | Parameter | Description |
   |--------|-------|
   | Database | Select the database to which the database change task belongs.  |
   | SQL Content | Select **<UI-TERM key="odc.components.CreateSQLPlanTaskModal.SqlEntry">SQL Entry</UI-TERM>** or **<UI-TERM key="odc.components.ImportDrawer.UploadFiles">Upload File</UI-TERM>**.<ul><li> **<UI-TERM key="src.component.Task.LogicDatabaseAsyncTask.CreateModal.0A3EB502">SQL Entry</UI-TERM>**: This is the default way to specify SQL content. You can directly write the SQL script in the editing area. <main id="notice" type='explain'><h4>Note</h4><ul><li>The maximum size of the SQL statements that can be entered in the SQL window is limited to 500,000 characters. If the SQL script to be executed has more than 500,000 characters, you can directly upload the script file. </li><li>You can click <strong>IN Value Conversion</strong> to convert the batch copied data into the `in('A','B')` format. </li><li>Column values are separated with line breaks. </li><li>Row values are separated with spaces or tabs. </li></ul></main> </li><li> **<UI-TERM key="odc.components.ImportDrawer.UploadFiles">Upload File</UI-TERM>**: Click the file pool to go to the file explorer and select the file to be imported. You can also directly drag the file to the file pool to upload it. <main id="notice" type='explain'><h4>Note</h4><ul><li>You can upload up to 500 files. The total file size cannot exceed 256 MB. </li><li>By default, files are sorted by the order in which they were uploaded. You can drag and drop them to change the order. Tasks are executed in the file order. </li><li>Only SQL files suffixed with `.sql` are supported. </li></ul></main> </li></ul> |
   | SQL Check | Click this icon to check the syntax of the SQL statement.  |
   | Rollback Plan | Specify **<UI-TERM key="src.component.Task.MutipleAsyncTask.CreateModal.D521A9F8">Rollback Plan</UI-TERM>**.  You can write an SQL script or upload a file to specify the rollback plan. For more information, see the description of **<UI-TERM key="odc.component.DetailModal.sqlPlan.SqlContent">SQL Content</UI-TERM>**. <main id="notice" type='explain'><h4>Note</h4><p>You can select <strong>Generate Backup Rollback Plan</strong> so that backup rollback SQL statements will be automatically generated for `UPDATE` and `DELETE` statements. </p><ul><li>For OceanBase Database in MySQL mode or MySQL Database, a rollback SQL statement can be generated only for an `UPDATE` or `DELETE` statement executed on a table with a primary or unique key. </li><li>A backup rollback SQL statement can be generated only when a database change statement affects no more than 100,000 rows and the database change task affects no more than 1 million rows. </li></ul></main> |
   | Delimiter | Delimiters are supported.  |
   | Query Result Limit | You can set the maximum number of rows allowed in the query result. Value range: 1 to 1000000.  |
   | Task Settings | <ul><li> **<UI-TERM key="src.component.Task.AsyncTask.DetailContent.1F4ECA8A">SQL Retry Attempts</UI-TERM>**: If you specify a value greater than `1`, when the execution of an SQL statement fails, ODC will re-execute the statement in 3 minutes. </li><li>The database change tool provides two error handling methods:<ul><li> **<UI-TERM key="odc.AlterDdlTask.CreateModal.StopATask">Abort Task</UI-TERM>**: This is the default option. When you select this option, the task is aborted if an error occurs when you run the script. </li><li> **<UI-TERM key="odc.AlterDdlTask.DetailContent.IgnoreErrorsToContinueThe">Ignore Error and Continue</UI-TERM>**: When you select this option, the system skips the erroneous statement where an error occurs and continues to execute other statements in the script. </li></ul></li><li> Select **<UI-TERM key="odc.DataClearTask.CreateModal.ExecuteNow">Execute Now</UI-TERM>** or **<UI-TERM key="odc.DataArchiveTask.CreateModal.ScheduledExecution">Scheduled Execution</UI-TERM>**. </li></ul> |
   | Execution Timeout Value | Specify the value in the **Execution Timeout Value** field in hours. Default value: 48. Maximum value: 480.  |
   | Description | You can enter a description of no more than 200 characters in **Task Description**. This field is optional.  |
3. Click **<UI-TERM key="workspace.header.create">Create</UI-TERM>**.

4. On the **<UI-TERM key="odc.SpaceContainer.Sider.Ticket">Tickets</UI-TERM>** tab, view the task information in the database change task list.

   ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/600.database-change/4EN.png)

## View a database change task

### Task information

1. In the database change task list on the **<UI-TERM key="odc.SpaceContainer.Sider.Ticket">Tickets</UI-TERM>** tab shown in the preceding figure, click **<UI-TERM key="workspace.window.sql.explain.button.showOutputFilter">View</UI-TERM>** in the **<UI-TERM key="odc.ExternalIntegration.SSO.Operation">Actions</UI-TERM>** column of the target task.

2. In the **<UI-TERM>Task Details</UI-TERM>** panel, click the **<UI-TERM>Task Information</UI-TERM>** tab to view the database, type, risk level, SQL content, and rollback statement of the task.

  <main id="notice" type='explain'>
     <h4>Note</h4>
     <p>You can click <strong>Download Backup Rollback Plan</strong> to download the rollback plan file automatically generated by ODC for `UPDATE` and `DELETE` statements. </p>
  </main>

![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/600.database-change/5EN.png)

3. Click **<UI-TERM key="odc.TaskManagePage.component.TaskTools.InitiateAgain">Initiate Again</UI-TERM>** to initiate the database change task again, or click **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskFlow.RollBack">Roll Back</UI-TERM>** to roll back the task.

### Task process

![6](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/600.database-change/6EN.png)

In the **<UI-TERM>Task Details</UI-TERM>** panel, click the **<UI-TERM key="odc.components.RecordPage.TaskFlow">Task Process</UI-TERM>** tab and view information such as the task initiation status, approval status, execution status, and execution result.


### Execution result

![7](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/600.database-change/7EN.png)

In the **<UI-TERM>Task Details</UI-TERM>** panel, click the **<UI-TERM key="odc.component.CommonIDE.Result">Execution Result</UI-TERM>** tab to view the execution success and failure records.

### Rollback ticket

In the **<UI-TERM>Task Details</UI-TERM>** panel, click **<UI-TERM key="odc.component.CommonDetailModal.RollbackTicket">Rollback Ticket</UI-TERM>** to view the rollback task.


### Task logs

![8](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/600.database-change/8EN.png)

In the **<UI-TERM>Task Details</UI-TERM>** panel, click the **<UI-TERM>Task Logs</UI-TERM>** tab to view all logs and alert logs of the task.


| Tab | Description |
|---------|--------------|
| All Logs | Displays the complete information of all task logs, including **<UI-TERM>INFO</UI-TERM>**, **<UI-TERM>ERROR</UI-TERM>**, and **<UI-TERM>WARN</UI-TERM>** logs.  You can click **<UI-TERM key="src.page.Workspace.SideBar.ResourceTree.DatabaseSearch.86200ED0">Search</UI-TERM>**, **<UI-TERM key="odc.TaskManagePage.component.TaskTools.Download">Download</UI-TERM>**, or **<UI-TERM key="odc.TreeNodeMenu.config.table.Copy">Copy</UI-TERM>** to search for, download, or copy all logs.  |
| Alert Logs | Displays the **<UI-TERM>ERROR</UI-TERM>** and **<UI-TERM>WARN</UI-TERM>** logs of the task. When a task fails, you can view the error message in the alert logs.  You can click **<UI-TERM key="workspace.window.session.button.search">Search</UI-TERM>**, **<UI-TERM key="odc.TaskManagePage.component.TaskTools.Download">Download</UI-TERM>**, or **<UI-TERM key="odc.TreeNodeMenu.config.view.Copy">Copy</UI-TERM>** to search for, download, or copy alert logs.  |
