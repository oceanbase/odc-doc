# Operation records

## Background information

You can view and export historical operation records in the OceanBase Developer Center (ODC) console.

## Operation record list

<main id="notice" type='explain'>
  <h4>Note</h4>
  <ul>
  <li>Any user who owns the system_admin role can manage operation records. </li>
  <li>Operation records are retained permanently. </li>
  </ul>
</main>

1. In the project collaboration window, choose **<UI-TERM key="odc.page.Secure.SafetySpecifications">Security Specifications</UI-TERM>** > **<UI-TERM key="odc.component.VersionModal.newVersionConfig.OperationRecords">Operation Records</UI-TERM>** to go to the **<UI-TERM key="odc.component.VersionModal.newVersionConfig.OperationRecords">Operation Records</UI-TERM>** page.

   <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/423/900.data-security-and-compliance/200.operating-records/1EN.png" width="900">

   * You can click the <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/icon/refresh.jpg" width="20" icon> icon to manually refresh the list.

   * You can select an option from **<UI-TERM>Execution Duration</UI-TERM>** to filter the operation records by time. Operation records in the last 7 days, 15 days, 30 days, or 6 months, or a custom time range can be queried.

2. View the basic information displayed in the operation record list.

   | Parameter | Description |
   |-------|------------|
   | No. | The sequence number of the operation record.  |
   | Event Type | The type of the operation event. The following types of operation events are supported: personal settings, password management, connection management, script management, database operations, organization configuration, member management, resource group management, data mocking, database changes, import, export, permission application, and task processes. You can click the filter icon <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/icon/filter.jpg" width="20" icon> to filter the operation records by event type. |
   | Event Operation | The operation performed in the event.  You can click the <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/icon/filter.jpg" width="20" icon> icon to filter the operation records by event operation.  |
   | IP Address | The IP address.  You can click the <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/icon/search.jpg" width="20" icon> icon to search by IP address.  |
   | Operator | The user who performed the operation.  You can click the <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/icon/search.jpg" width="20" icon> icon to search by operator.  |
   | Execution Time | The time when the operation was performed.  By default, the operation records are sorted by execution time. The latest record is displayed at the top.  You can click the <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/icon/ascending%20and%20descending%20order.jpg" width="20" icon> icon to sort the operation records in ascending or descending order of execution time.  |
   | Execution Result | The execution result. Valid values: **<UI-TERM key="odc.components.SQLResultSet.SuccessfulExecution">Succeeded</UI-TERM>** and **<UI-TERM key="odc.component.RecordPopover.components.Failed">Failed</UI-TERM>**.  You can click the <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/icon/filter.jpg" width="20" icon> icon to filter the operation records by execution result.  |
   | Actions | Provides options for you to manage the record. Currently, only **<UI-TERM key="src.component.Task.component.CommonDetailModal.178F11D7">View</UI-TERM>** is available.  |

## View details of an operation record

In the operation record list, click **<UI-TERM key="odc.components.SensitiveRule.View">View</UI-TERM>** in the **<UI-TERM key="odc.Secure.MaskingAlgorithm.Operation">Actions</UI-TERM>** column of an operation record. The **<UI-TERM key="odc.component.RecordPopover.components.RecordDetails">Record Details</UI-TERM>** panel appears.

<img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/423/900.data-security-and-compliance/200.operating-records/2EN.png" width="900">

You can view the event type, event operation, IP address, execution details, executor, execution time, and execution result of the operation record.

## Export operation records

Click the <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/icon/export.jpg" width="20" icon> icon in the upper-left corner of the **<UI-TERM key="odc.page.Secure.OperationRecord">Operation Records</UI-TERM>** page to go to the **<UI-TERM key="odc.components.RecordPage.ExportOperationRecords">Export Operation Records</UI-TERM>** panel.

The following table describes the parameters that you can specify when you export operation records.

<img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/423/900.data-security-and-compliance/200.operating-records/3EN.png" width="900">

| Parameter | Description |
|--------|---------------|
| Operation Time Range | Select the start date and the end date.  |
| Event Operation | Select event operations.  |
| Connection | Select data sources whose operation records that you want to export.  By default, all data sources are selected.  |
| Operator | You can specify to export operation records of specific operators.  |
| Execution Result | Select the execution result.  |
| Export Format | Select the format for exported data. Supported formats are Excel and CSV.  |
