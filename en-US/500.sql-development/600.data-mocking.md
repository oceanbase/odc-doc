# Generate test data

## Background information

OceanBase Developer Center (ODC) provides the data mocking feature for you to quickly generate data based on the field types of an existing table in scenarios that require a large amount of mock data, such as database performance testing and feature verification.

## Considerations

* At most 100 million rows can be mocked at a time.

* Data mocking is not supported for a table with `CHECK` constraints.

* Data mocking is not supported for RANGE- or LIST-partitioned tables.

* Data mocking is not supported for a table that is encoded by using ZHSGB2312.

## Create a data mocking task

Example: On the **<UI-TERM key="odc.page.Project.Ticket">Tickets</UI-TERM>** tab, generate mock data based on an existing table in the database.

| Parameter | Example value |
| --- | --- |
| Project name | odc_4.2.0 |
| Database name | odc_test |
| Table name | employee |

1. In the SQL window, choose **<UI-TERM key="odc.SpaceContainer.Sider.Ticket">Tickets</UI-TERM>** > **<UI-TERM key="odc.TreeNodeMenu.config.table.AnalogData">Mock Data</UI-TERM>** > **<UI-TERM>Create Mock Data Task</UI-TERM>**.

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/sql-development/data%20mocking/1.png)

2. In the **<UI-TERM>Create Mock Data Task</UI-TERM>** panel, configure the following parameters.

    ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/sql-development/data%20mocking/2.png)

    | Parameter | Description |
    | --- | --- |
    | Database | Select the target database `odc_test`. |
    | Table | Select the `employee` table in the `odc_test` database to generate mock data based on this table. |
    | Mock Data Volume | Specify the number of rows to be generated. The default value is `1000`. At most 100 million rows can be generated. You can enter a value ranging from 1 to 100,000,000. |
    | Batch Size | Specify the number of rows that triggers a commit by using the `COMMIT` command. By default, a commit is performed each time when 200 rows are generated. The maximum value is `500`. You can enter an integer ranging from 1 to 500. |
    | Truncate Table Before Inserting Mock Data | Specify whether to clear the original data before inserting mock data into the table. |
    | Data Conflict Handling Mode | Select the handling method when the inserted data conflicts with the original data in the table. Valid values:<ul><li>**<UI-TERM key="src.d.ts.C34AA00A">Ignore</UI-TERM>**: This option is selected by default. The data conflicting with existing data is not inserted. </li><li>**<UI-TERM key="odc.component.DataMockerDrawer.type.Cover">Overwrite</UI-TERM>**: If a data conflict occurs, the original data is deleted, and the new data is inserted. </li><li>**<UI-TERM key="src.page.Workspace.components.SQLResultSet.D3F95049">Terminate</UI-TERM>**: If a data conflict occurs, the data mocking task is terminated. </li></ul> |
    | Rule Settings | Set the data generation rules. <br>In the **<UI-TERM key="odc.component.DataMockerDrawer.RuleConfigTable.Rules">Rule</UI-TERM>** and **<UI-TERM key="odc.component.DataMockerDrawer.RuleConfigTable.Rules.1">Rule Details</UI-TERM>** columns, set the mock data generation rules for the fields in the selected table. Some built-in rules are provided in the **<UI-TERM key="odc.component.DataMockerDrawer.RuleConfigTable.Rules">Rule</UI-TERM>** column based on the field type.  The **<UI-TERM key="odc.component.DataMockerDrawer.RuleConfigTable.Rules.1">Rule Details</UI-TERM>** column displays the details about the selected rule. You can click the Edit icon to edit the details. |
    | Task Settings | Select **<UI-TERM key="odc.DataArchiveTask.CreateModal.ExecuteNow">Execute Now</UI-TERM>** or **<UI-TERM key="odc.DataClearTask.CreateModal.ScheduledExecution">Scheduled Execution</UI-TERM>**. |

3. Click **<UI-TERM key="odc.src.page.Project.Sensitive.components.SensitiveColumn.components.Submit">Submit</UI-TERM>** to generate a data mocking task.

4. After the task is generated, the **<UI-TERM key="odc.SpaceContainer.Sider.Ticket">Tickets</UI-TERM>** tab automatically appears, where you can view the approval status and basic information of the task.

    ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/sql-development/data%20mocking/3.png)

## View a data mocking task

### Task information

1. In the data mocking task list on the **<UI-TERM key="odc.page.Project.Ticket">Tickets</UI-TERM>** tab, click **<UI-TERM key="src.page.Project.Notification.components.445FB17E">View</UI-TERM>** in the **<UI-TERM key="odc.component.CommonDetailModal.TaskExecuteRecord.Operation">Actions</UI-TERM>** column of the target task. In the **<UI-TERM>Task Details</UI-TERM>** panel of the target task, click the **<UI-TERM>Task Information</UI-TERM>** tab in the upper-right corner to view the basic task information and data mocking settings.

    ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/sql-development/data%20mocking/3.png)

    | Item | Description |
    | --- | --- |
    | Basic task information | The ID, connection, database, type, execution mode, creator, and creation time of the task are displayed. |
    | Data mocking settings | The target table, number of rows to generate, number of rows committed at a time, whether to truncate the table before inserting data, handling method for data conflicts, inserted records, conflict records, whether to ignore data conflicts, cleanup records, and rule settings are displayed. |

2. On the **<UI-TERM>Task Information</UI-TERM>** tab, click **<UI-TERM key="odc.TaskManagePage.component.TaskTools.InitiateAgain">Initiate Again</UI-TERM>** or **<UI-TERM key="odc.components.TriggerPage.Download">Download</UI-TERM>** in the lower-right corner to initiate the task again or download the mock data file to your local disk.

### Task logs

In the data mocking task list on the **<UI-TERM key="odc.page.Project.Ticket">Tickets</UI-TERM>** tab, click **<UI-TERM key="src.component.Task.StructureComparisonTask.DetailContent.DF21DA79">View</UI-TERM>** in the **<UI-TERM key="src.page.Workspace.components.SQLResultSet.F84FA469">Actions</UI-TERM>** column of the target task. In the **<UI-TERM>Task Details</UI-TERM>** panel of the task, click the **<UI-TERM>Task Logs</UI-TERM>** tab in the upper-right corner to view all logs and alert logs of the task.

| Tab | Description |
| --- | --- |
| All Logs | Displays the complete information of all task logs, including **<UI-TERM>INFO</UI-TERM>**, **<UI-TERM>ERROR</UI-TERM>**, and **<UI-TERM>WARN</UI-TERM>** logs. |
| Alert Logs | Displays the **<UI-TERM>ERROR</UI-TERM>** and **<UI-TERM>WARN</UI-TERM>** logs of the task.  When a task fails, you can view the error message in the alert logs. |

In addition, the toolbar provides the following icons:

| Icon | Description |
| --- | --- |
| Search | Click this icon to search for logs. |
| Download | Click this icon to download logs. |
| Copy | Click this icon to copy logs. |

## Download mock data

In the data mocking task list on the **<UI-TERM key="odc.SpaceContainer.Sider.Ticket">Tickets</UI-TERM>** tab, click **<UI-TERM key="odc.components.PackagePage.Download">Download</UI-TERM>** in the **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskDetails">Ticket Details</UI-TERM>** panel of the task to download the created mock data to your local disk. You can view the exported mock data file in your local disk.

![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/sql-development/data%20mocking/3.png)
