# Create a trigger

Log in to OceanBase Developer Center (ODC) and click the name of the target connection to go to the corresponding connection management page. You can click **<UI-TERM key="odc.ResourceTree.Nodes.trigger.Trigger">Trigger</UI-TERM>** in the left-side navigation pane to get a list of triggers. To create a trigger, click **+** in the upper-right corner of the trigger list or click **<UI-TERM key="odc.SensitiveRule.components.FormSensitiveRuleDrawer.Create">Create</UI-TERM>** in the navigation bar on the top of the page

To create a trigger, perform the following three steps:

1. Specify the basic information.

2. Configure the advanced settings.

3. Verify the SQL statement.

![Image 228](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9951704161/p242686.png)

## Specify the basic information

This is Step 1. The **<UI-TERM key="odc.components.CreateTable.BasicInformation">Basic Information</UI-TERM>** section contains the following parameters:

* **<UI-TERM key="odc.CreateTriggerPage.component.BaseInfoForm.TriggerName">Trigger Name</UI-TERM>**: specifies the name of the trigger.

* **Base Object Mode**: specifies the schema where the object that the trigger works on is located.

* **<UI-TERM key="odc.CreateTriggerPage.component.BaseInfoForm.BaseObjectType">Base Object Type</UI-TERM>**: specifies the type of the object that the trigger works on. The current version supports only **TABLE** objects.

* **<UI-TERM key="odc.CreateTriggerPage.component.BaseInfoForm.BaseObjectName">Base Object Name</UI-TERM>**: specifies the name of the object that the trigger works on.

* **<UI-TERM key="odc.CreateTriggerPage.component.BaseInfoForm.TriggerStatus">Trigger Status</UI-TERM>**: specifies the state of the trigger. Valid value: **On** or **<UI-TERM key="odc.components.RolePage.Disable">Disable</UI-TERM>**.

## Configure the advanced settings

This is Step 2. The **<UI-TERM key="src.component.Task.DataArchiveTask.CreateModal.CC365F6B">Advanced Settings</UI-TERM>** section contains the following parameters:

* **<UI-TERM key="odc.CreateTriggerPage.component.AdvancedInfoFrom.TriggerType">Trigger Type</UI-TERM>**: specifies the type of the trigger. The current version supports only **SIMPLE** triggers.

* **<UI-TERM key="odc.ResourceTree.Nodes.trigger.Trigger">Trigger</UI-TERM>**: specifies whether the trigger is activated before or after the triggering event. Valid value: **BEFORE** or **AFTER**.

* **<UI-TERM key="odc.CreateTriggerPage.component.AdvancedInfoFrom.Level">Level</UI-TERM>**: specifies the level of the trigger. The current version supports only row-level triggers.

* **<UI-TERM key="src.page.Project.Notification.components.3F3F37F5">Event</UI-TERM>**: specifies the type of operation that activates the trigger. Valid value: **INSERT** , **UPDATE** , or **DELETE** .

* **Column (Optional)**: specifies the range that the event specified in **<UI-TERM key="odc.CreateTriggerPage.component.AdvancedInfoFrom.Event">Event</UI-TERM>** applies to. This parameter is displayed when you set **<UI-TERM key="src.page.Project.Notification.components.6C61DE34">Event</UI-TERM>** to **UPDATE** . The current version allows you to create only row-level triggers in a table. Therefore, the range here is the columns that the event applies to.

* **Referencing Old (Optional)**: specifies an alias for the referenced object that corresponds to the value specified for `REFERENCEING OLD` in the trigger creation statement.

* **Referencing New (Optional)**: specifies an alias for the referenced object that corresponds to the value specified for `REFERENCEING NEW` in the trigger creation statement.

* **Clause Condition (Optional)**: specifies a logical expression for the trigger. After you specify a clause condition, the action specified by the trigger is executed only if the value of the expression is True.

## Verify the SQL statement

After you specify all the information in the **<UI-TERM key="odc.components.TriggerPage.BasicInformation">Basic Info</UI-TERM>** and **<UI-TERM key="src.component.Task.DataArchiveTask.CreateModal.CC365F6B">Advanced Settings</UI-TERM>** sections, click **<UI-TERM key="odc.components.CreateTable.EditToolbar.NextStepConfirmSql">Next: Verify SQL Statement</UI-TERM>** to go to the statement editing page.

The trigger definition statement is generated on the statement editing page based on the information that you specified in the **<UI-TERM key="workspace.window.sequence.propstab.info">Basic Info</UI-TERM>** and **<UI-TERM key="src.component.Task.DataClearTask.CreateModal.85DFDA54">Advanced Settings</UI-TERM>** sections. You only need to complete the trigger body, which specifies the action to be executed. After you complete the trigger body, click the **<UI-TERM key="src.page.Project.User.ManageModal.Table.CreateAuth.35C819CB">Create</UI-TERM>** button in the upper-right corner of the page to complete the creation of the trigger.

In addition, the toolbar on the editing page provides the following buttons:

| Button | Description |
| --- | --- |
| Format | Click this button to apply formatting, such as indentation, line break, and keyword highlighting, to the selected SQL statements or all the SQL statements in the current SQL window. |
| Find and Replace | You can specify search criteria in the search box to find specific content in the script and enter other content in the replacement box to replace the content found. |
| Undo | Click this button to undo the last operation. |
| Redo | Click this button to reverse an **<UI-TERM key="odc.EditorToolBar.actions.text.Revocation">Undo</UI-TERM>** operation. |
| Case Sensitivity | The system supports three configurations: **<UI-TERM key="odc.ruleItems.CharItem.AllUppercase">All Caps</UI-TERM>** , **<UI-TERM key="odc.EditorToolBar.actions.text.AllLowercase">All Lowercase</UI-TERM>** , and **Capitalize the first letter** . Click this button to convert the selected statements in the script to the corresponding capitalization format. |
| Indent | The **Add Indents** and **<UI-TERM key="odc.EditorToolBar.actions.text.DeleteIndentation">Delete Indent</UI-TERM>** options are provided, to allow you to add indents to or delete indents from the selected statements in the script. |
| Comment | The **Add Comments** and **<UI-TERM key="odc.EditorToolBar.actions.text.DeleteComments">Delete Comment</UI-TERM>** options are provided, which respectively allow you to convert the selected statements in the script to comments and convert comments to SQL statements. |
| Previous | Click this button to go back to the **<UI-TERM key="odc.ResourceTree.actions.CreateATrigger">Create Trigger</UI-TERM>** page, where you can continue to edit or modify the parameters in the **<UI-TERM key="odc.components.CreateTable.BasicInformation">Basic Information</UI-TERM>** and **<UI-TERM key="src.component.Task.DataClearTask.CreateModal.85DFDA54">Advanced Settings</UI-TERM>** sections. |
