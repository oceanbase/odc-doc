## 升级注意事项

- 数据源

 - ODC V4.2.0 及之后的版本，连接配置概念调整为数据源。

 - ODC V4.2.0 及之后的版本，个人连接迁移到个人空间，以数据源的形式存在。

 - ODC V4.2.0 及之后的版本，公共连接迁移到团队空间，以数据源的形式存在。

 - ODC V4.2.0 及之后的版本，原公共连接中的只读、读写账号，升级后仅保留读写账号。

- 用户权限

 - private_connection/apply_connection 角色已在 ODC V4.2.0 及之后的版本中下线，升级到 ODC V4.2.x 版本的用户引用的 private_connection/apply_connection 角色对应的权限不再生效。

 - 资源组已在 ODC V4.2.0 及之后的版本中下线。

 - 连接访问权限已在 ODC V4.2.0 及之后的版本中下线，ODC V4.2.x 中通过项目管控实现对数据库的访问控制。

- 系统设置

 - 已 ODC V4.2.0 及之后的版本中下线。

- 工单模块

 - ODC V4.2.0 之前的版本发起的工单仅支持在 **<UI-TERM key="odc.component.TaskPopover.IInitiated">我发起的</UI-TERM>** 的分类下查看用户自己发起的工单。

- 分区计划

 - 该功能在 ODC V4.2.0 版本中升级，升级到 ODC V4.2.x 版本后，在 ODC V4.2.0 之前版本创建的历史分区计划任务将停止运行。

- SQL 计划

 - 该功能在 ODC V4.2.0 版本中升级，升级到 ODC V4.2.x 版本后，在 ODC V4.2.0 之前版本创建的历史 SQL 计划任务将停止运行。

- 任务流程

 - 该功能模块在 ODC V4.2.0 及之后的版本中下线，ODC V4.2.x 中已上线风险等级模块实现对应效果。

- 数据脱敏

 - 该功能模块在 ODC V4.2.0 版本中升级，升级到 ODC V4.2.x 版本后，在 ODC V4.2.0 之前版本创建的数据脱敏配置不再生效。

- 历史会话

 - 历史会话在 ODC V4.2.0 及之后的版本中下线，ODC V4.2.x 中默认会保存 SQL 窗口的使用状态。

## ODC V4.3.3-BP2

### 版本信息

* **当前版本**：V4.3.3-BP2

* **前置版本**：V4.3.3-BP1

* **发版时间**：2025 年 03 月 04 日

* **支持的升级路径**：对于 ODC V2.0.0 及之后的版本，均可直接升级至本版本。

### 功能变更

- 数据归档

  - 将数据库中的数据归档到对象存储时支持清理源端已归档数据和生成的临时表。

  - 将数据库中的数据归档到对象存储时执行超时，再次执行该任务时 ODC 会从断点位置继续归档数据。

  - 将数据库中的数据归档到对象存储时支持定义目标文件名。

* 数据源

  - 适配 OceanBase V4.3.5.1 版本。

### 问题修复

- SQL 开发

  - 修复 SQL 窗口中执行 `SET nls_date_format='DD-MON-RR'` 后日期格式未变更的缺陷。

- SQL 计划

  - 修复个人空间工作模式下，SQL 计划的任务详情中无操作记录内容的缺陷。

  - 修复 SQL 计划的 **<UI-TERM>工单描述</UI-TERM>** 内容未同步到任务生成的数据库变更的 **<UI-TERM>工单描述</UI-TERM>** 中的缺陷。

- 数据归档/数据清理

  - 修复取消数据清理和数据归档任务后，未释放后台任务进程的缺陷。

  - 修复执行数据清理过程中，清理源表后修改行限流，行限流不生效的缺陷。

  - 修复终止数据归档任务后，任务状态显示错误的缺陷。

- 模拟数据

  - 修复再次发起模拟数据时，因模拟数据包含顺序类型规则数据导致执行任务报错的缺陷的缺陷。

- 权限申请

  - 修复申请库权限/项目/表权限时，无待审批消息通知的缺陷。

- 项目

  - 修复用户未加入任何项目时，未显示 **<UI-TERM>加入项目</UI-TERM>** 入口的缺陷。

- 其他

  - 修复新建分区计划任务时，**<UI-TERM>设置分区策略</UI-TERM>** 页面中的 **<UI-TERM>如何配置</UI-TERM>** 文档参考链接错误的缺陷。

## ODC V4.3.3

本次 1 月发版的 OceanBase 开发者中心（OceanBase Developer Center，ODC）V4.3.3 版本主要更新以下功能：

- 数据归档：本版本提供了一系列功能来优化数据归档流程，包括支持将数据库中的数据以 CSV 格式归档到多种对象存储服务（如阿里云 OSS、腾讯云 COS、华为云 OBS 和 AWS S3）。引入了批量配置归档表的功能，极大地提高了大规模归档任务的配置效率。允许用户定义动态目标表，以满足按照日或月等周期单独存储历史数据的需求。此外，改进了自定义变量的偏移量设置与计算逻辑，增强了灵活性和准确性。

- 项目管理：引入了全局项目角色，如全局项目管理员、安全管理员和 DBA 角色，以解决平台负责人无法有效管控所有项目资源的问题。同时优化了工单被管理及查看逻辑，管理员和 DBA 可管理项目内的所有工单，项目成员可查看项目内所有工单，以保证项目内的变更可控。

- 内核适配：为了更好地支持 OceanBase ，本版本实现了外表管理的白屏化，增加了展示分区表二级分区信息的功能，并适配了 ODP 指定 OBServer IP 路由功能。此外本版本还适配了 OceanBase V4.2.5、V4.3.3 版本及 OBKV SQL 模式。

更多详情，请参见功能变更。

### 版本信息

* **当前版本**：V4.3.3

* **前置版本**：V4.3.2-BP3

* **发版时间**：2025 年 01 月 17 日

* **支持的升级路径**：对于 ODC V2.0.0 及之后的版本，均可直接升级至本版本。

### 功能变更

- 数据归档

 - 支持将数据库中的数据归档到对象存储，本期支持的对象存储包括阿里云 OSS、腾讯云 COS、华为云 OBS、AWS S3，文件格式为 CSV 格式。

 - 支持批量配置归档表，提效大规模归档任务配置。

 - 支持定义动态目标表，解决按日、月等单独存放历史数据的诉求。

 - 自定义变量支持设置偏移量为 0，并优化偏移量计算逻辑。

 - 优化了原生 MySQL、Oracle 数据库的防导爆逻辑，主动根据活跃会话数占比限流。

 - 优化回滚逻辑，仅回滚当次任务的归档数据。

 - 支持回溯编辑历史，支持查看编辑内容前后对比。

 - 支持删除数据归档、清理任务，当任务已完成或已终止时支持对其进行删除操作。

- 项目管理

 - 增加全局项目角色，包括全局项目管理员、全局安全管理员以及全局 DBA 项目角色。全局项目角色的引入可解决平台负责人无法管控平台所有项目资源的痛点。

 - 支持用户登出再登入后仍旧可以定位在最近使用的项目下，简化用户操作路径。

 - 支持固化项目搜索条件，避免频繁搜索高频操作项目。

 - 增加项目归档检测机制，归档前会检测项目中是否存在未结束的工单及周期任务。

 - 支持删除项目，对于已归档的项目支持对其进行删除操作。

 - 支持用户申请视图权限，对用户访问视图做了更细粒度的权限控制。

- 工单

 - 工单可被管理及查看范围调整，管理员和 DBA 可管理项目内所有工单，其它角色仅可管理自己发起的工单。同时项目内所有成员均可查看项目内所有工单。

 - 除逻辑库变更, 分区计划, 影子表外，所有工单类型支持再次发起功能，再次发起后支持二次编辑工单参数。

 - 项目外工单模块增加项目列，方便用户快速识别工单所属项目。

- SQL 开发

 - 新支持了 OceanBase 外表白屏化管理。

 - 支持了 OceanBase 分区表的二级分区展示。

 - 支持编辑 OceanBase MySQL 模式的存储/函数过程。

 - 优化连接保活逻辑，每3分钟会主动发送一次数据库请求，保障连接的稳定性。

- 安全规范

 - SQL 窗口拓展了可执行的 SQL 类型，新支持了 `CALL`、`COMMENT`、`SET SESSION` 等类型。

 - SQL 检查规范了支持原生 Oracle 数据源。

 - 支持原生 Oracle 数据源的变更走变更审批流程。

 - 风险识别规则中判断条件文案优化，统一采用运算符及英文表达，以避免歧义。

 - 新增 2 条 SQL 检查规范，支持规范 `CREATE LIKE` 及 `CREATE AS` 建表语句。

- 无锁结构变更

 - 支持失败重试，为各环节可能导致失败的场景补充重试逻辑。

 - 支持无锁结构变更状态展示，可以查看运行中任务进度。

- 其他

 - 支持 SAML 的单点登录方式。

 - 支持查杀原生 Oracle 数据源的会话。

 - 适配 OceanBase V4.2.5、V4.3.3 版本。

 - 适配 OBKV SQL 模式。

 - 适配 ODP 指定 OBSERVER IP 路由功能。

 - 启用 Secure Cookie 机制，加固数据传输安全。

 - 平台表单（含工单列表、数据库列表）列宽支持拉伸。

 - 明确自动授权多条件组合「与或」逻辑，目前采用「与」逻辑。

### 问题修复

- 数据源

 - 修复堡垒机集成场景下，无法同步 `information_schema` 等内置数据库到项目中的缺陷。

- 工单

  - 修复创建数据归档已执行成功，工单仍显示审批流程的缺陷。

  - 修复数据归档/数据清理任务已执行成功，但执行记录状态显示异常的缺陷。

  - 修复无法正常执行非当前账号创建的结构对比任务的缺陷。

  - 修复导出 Oracle 模式的表结构时，因存在虚拟列导致导出失败的缺陷。

  - 修复 OceanBase MySQL 类型源端数据库或者目标数据库所属表的 DDL 中指定全文索引的分词器，结构比对任务失败的缺陷。

  - 修复创建 MySQL 类型结构比对任务时，因数据库中包含 Year 类型的表导致生成的 DDL 有误的缺陷。

  - 修复定时任务包含过多子任务时，查看操作记录失败的缺陷。

- 变更管控

  - 修复无导出权限却能导出视图的缺陷。

  - 修复因无法禁用分区计划任导致无法归档项目的缺陷。

- SQL 开发

  - 修复 SQL Check 特定场景下产生 NPE 异常的缺陷。

  - 修复执行 `DROP PL` 需要数据库变更任务的权限的缺陷。

  - 修复函数返回值的数据类型为 Year 时，返回值无法正常显示的缺陷。

  - 修复 PL 名称包含 `@` 时，执行 `CREATE` 和 `DROP` 语句失败的缺陷。

  - 修复查询 Oracle 扩展统计信息（`DBMS_STATS.CREATE_EXTENDED_STATS`）的表详情失败的缺陷。
    
  - 修复限制 SQL 影响的行数时，执行 `INSERT` 语句不生效的缺陷。

  - 修复导出数组函数结果集时，空指针异常的缺陷。

  - 修复使用谷歌浏览器 Chrome 118 版本打开 Web 版 ODC SQL 窗口，鼠标右键单击程序包包头中的子程序时无运行按钮的缺陷。
    
  - 修复查看程序包包头中的子程序时报错的缺陷。

- 其他

 - 修复用户再次登录 Web 版 ODC 时未打开上次使用的项目的缺陷。

### 已知问题

* 客户端版 ODC 不支持安装在中文目录名中。

* 导出包含虚拟列的表时，导出的数据文件和内容显示异常。

* Web 版 ODC 中，结构或数据的导入量上限为 2GB，超限文件无法上传。

* Web 版 ODC 中，结构或数据的导出量上限为 2GB，超限会导致最终导出数据不完整。

* 导出任务详情中，导出对象的数据总记录数依赖 OceanBase 数据库视图，并非精准值。

* 需设置 `ob_enable_trace_log` 参数为 `on`，否则只显示首次执行的 SQL 的执行计划。
