# 新建序列

在 OceanBase 开发者中心（OceanBase Developer Center，ODC）单击连接名进入一个 Oracle 模式的连接后，在左导航栏中单击 **<UI-TERM key="odc.src.d.ts.Sequence">序列</UI-TERM>** 标签可以查看序列列表。在序列列表的右上角，单击 **<UI-TERM>+</UI-TERM>** 创建序列，或是在 ODC 上方导航栏中单击 **<UI-TERM>新建</UI-TERM>** \> **<UI-TERM>序列</UI-TERM>** 以创建所需的对象。创建序列有以下两个步骤：

![1](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4729171361/p138331.png)

1. 设置 **<UI-TERM key="workspace.window.sql.explain.tab.detail.card.base.title">基本信息</UI-TERM>**：需指定 **<UI-TERM key="workspace.window.createSequence.baseInfo.name">序列名称</UI-TERM>** 和 **<UI-TERM>当前用户</UI-TERM>** （根据当前连接账号自动填充）。

2. **<UI-TERM>设置列</UI-TERM>** （可选）。在该步骤需指定以下信息：

    | 信息项 | 说明 |
    | --- | --- |
    | 起始于 | 指定序列的起始值，要保证不小于属性 **<UI-TERM key="odc.components.CreateSequenceModal.MinimumValue">最小值</UI-TERM>** 。 |
    | 增量 | 指定序列值自增时的步长，可以为负数。 |
    | 最小值 | 指定序列可获取的最小值，数据库支持的最小值为-10^26。 |
    | 最大值 | 指定序列可获取的最大值，数据库支持的最大值为 10^27。 |
    | 缓存设置 | 指定序列缓存的大小，合理设置缓存值可以提高序列取值的执行性能，也可设置 **<UI-TERM key="workspace.window.createSequence.params.cached.no">无缓存</UI-TERM>** 。 |
    | 是否排序 | 指定序列的取值是否有序，有序取值场景下，序列的取值性能不如无序。 |
    | 是否循环 | 指定序列取值超过指定的最大值后，是否重新从最小值开始取值。 |

3. 单击 **<UI-TERM key="odc.components.CreateTriggerPage.NextConfirmTheSqlStatement">下一步：确认 SQL</UI-TERM>** 按钮后，进入SQL创建确认页面。

    ![确认](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4729171361/p326072.png)

4. 根据您指定的信息会预生成一个 SQL 脚本，检查 SQL 脚本无误后，单击页面右上角的 **<UI-TERM key="odc.EditorToolBar.actions.sql.Create">创建</UI-TERM>** 按钮，开始执行脚本并生成序列。
