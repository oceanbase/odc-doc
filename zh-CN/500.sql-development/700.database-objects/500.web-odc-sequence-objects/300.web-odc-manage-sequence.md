# 管理序列

在 OceanBase 开发者中心（OceanBase Developer Center，ODC）单击连接名进入一个 Oracle 模式的连接后，在左导航栏中单击 **<UI-TERM key="odc.src.d.ts.Sequence">序列</UI-TERM>** 标签可以查看序列列表。

您可以在序列列表中右键目标对象以进行一些 **管理操作** 。或者，在序列列表中双击目标序列名进入 **序列管理页面**。

![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/900.database-objects/5.web-odc-sequence-objects/1.0.png)

## 管理操作

在序列列表中，序列对象名称默认支持按头字符升序排序。
在序列列表中右键目标对象，在弹出的右键管理操作列表中 ODC 提供了一些操作键供您快速管理目标对象。

下述为管理操作键表：

| 操作键 | 说明 |
| --- | --- |
| 新建序列 | 进入新建序列页面，根据步骤创建新的序列对象。 |
| 查看序列 | 进入 **序列管理页面**，全量查看当前序列的基本信息、属性和 DDL 等信息。 |
| 修改 | 进入 **序列管理页面** 的属性部分修改当前序列的信息。 |
| 删除 | 删除当前序列。 |
| 导出 | 导出对象，默认导出当前对象，同时支持同时导出多个对象。具体请参见本手册文档 **导入和导出**。 |
| 下载 | 下载序列对象的 SQL 文件。 |
| 刷新 | 对当前序列对象进行一些管理操作后，刷新列表以展示最新信息。 |

## 序列管理页面

您可以在序列管理页面查看以下信息：

* **<UI-TERM key="workspace.window.sequence.propstab.info">基本信息</UI-TERM>** ：展示 **<UI-TERM key="workspace.window.createSequence.baseInfo.name">序列名称</UI-TERM>** 和 **<UI-TERM key="odc.component.Login.RegisterForm.Username">用户名</UI-TERM>** 等信息。

* **<UI-TERM key="workspace.window.table.toptab.props">属性</UI-TERM>** ：展示属性 **<UI-TERM key="odc.components.SequencePage.NextBufferValue">下一个缓冲值</UI-TERM>** 、 **<UI-TERM key="workspace.window.createSequence.params.increament">增量</UI-TERM>** 、 **<UI-TERM key="odc.components.CreateSequenceModal.MinimumValue">最小值</UI-TERM>** 、 **<UI-TERM key="odc.components.CreateSequenceModal.MaximumValue">最大值</UI-TERM>** 、 **<UI-TERM key="odc.components.SequencePage.CacheSettings">缓存设置</UI-TERM>** 、 **<UI-TERM key="odc.components.SequencePage.Sort">是否排序</UI-TERM>** 和 **<UI-TERM key="odc.components.SequencePage.LoopOrNot">是否循环</UI-TERM>** 等信息。其中 **<UI-TERM key="odc.components.SequencePage.NextBufferValue">下一个缓冲值</UI-TERM>** 展示的是序列视图中 `last_number` 的值，该值仅做展示不允许修改。

* **<UI-TERM key="workspace.window.table.propstab.ddl">DDL</UI-TERM>** ：展示定义序列的脚本。
