# 新建触发器

在 OceanBase 开发者中心（OceanBase Developer Center，ODC）单击连接名进入连接后，在左导航栏中单击 **<UI-TERM key="odc.components.ResourceTree.Trigger">触发器</UI-TERM>** 标签可以查看触发器列表。在触发器列表的右上角，单击 **+** 创建触发器，或是在上方导航栏中单击 **<UI-TERM key="odc.components.RecordPage.Create">新建</UI-TERM>** 以创建您需要的对象。

创建触发器需要进行以下 3 步操作：

1. 指定基本信息。

2. 设置高级设置信息。

3. 确认 SQL。

![Image 228](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9951704161/p242686.png)

## 指定基本信息

在新建触发器页面，第一步需要指定基本信息。 **<UI-TERM key="workspace.window.sequence.propstab.info">基本信息</UI-TERM>** 页签中包含以下信息项：

* **触发器名称**：为触发器指定一个名称。

* **<UI-TERM key="odc.CreateTriggerPage.component.BaseInfoForm.ReferenceObjectMode">基准对象模式</UI-TERM>**：触发器作用的对象所在的 Schema。

* **<UI-TERM key="odc.CreateTriggerPage.component.BaseInfoForm.BaseObjectType">基准对象类型</UI-TERM>**：触发器作用的对象的类型，当前版本只支持 **TABLE** 表对象。

* **<UI-TERM key="odc.CreateTriggerPage.component.BaseInfoForm.BaseObjectName">基准对象名称</UI-TERM>**：触发器作用的对象的名称。

* **<UI-TERM key="odc.CreateTriggerPage.component.BaseInfoForm.TriggerStatus">触发器状态</UI-TERM>**：指定当前触发器为 **<UI-TERM key="odc.components.RecordPage.Enable">启用</UI-TERM>** 或 **<UI-TERM key="odc.ResourceTree.config.procedure.Disable">禁用</UI-TERM>** 。

## 设置高级设置信息

指定基本信息后，第二步需要指定一些高级设置信息。 **<UI-TERM key="src.component.Task.DataArchiveTask.CreateModal.CC365F6B">高级设置</UI-TERM>** 页签包含以下信息项：

* **<UI-TERM key="odc.CreateTriggerPage.component.AdvancedInfoFrom.TriggerType">触发器类型</UI-TERM>**：选择触发器的类型，当前版本只支持创建 **SIMPLE** 简单触发器。

* **<UI-TERM key="odc.CreateTriggerPage.component.AdvancedInfoFrom.Trigger">触发</UI-TERM>**：指定触发时间，即该触发器是在触发事件发生之前（ **BEFORE** ）或之后（ **AFTER** ）触发。

* **<UI-TERM key="odc.CreateTriggerPage.component.AdvancedInfoFrom.Level">级别</UI-TERM>**：指定触发器的级别。当前版本只支持行级别触发器（Row-level）。

* **<UI-TERM key="src.page.Project.Notification.components.68CAD20E">事件</UI-TERM>**：指定会触发此触发器的操作，支持选择 **INSERT** 、 **UPDATE** 和 **DELETE** 事件。

* **列（选填）**：指定 **<UI-TERM key="src.page.Project.Notification.components.6C61DE34">事件</UI-TERM>** 作用的范围，在 **<UI-TERM key="src.page.Project.Notification.components.6C61DE34">事件</UI-TERM>** 中选择 **SELECT** 事件后展示该项。当前版本只支持在表对象中创建行级触发器，所以这里要选择事件作用的列。

* **引用旧值（选填）**：为引用的对象指定一个别名，对应触发器创建语法中 `REFERENCEING OLD` 的值。

* **引用新值（选填）**：为引用的对象指定一个别名，对应触发器创建语法中 `REFERENCEING NEW` 的值。

* **子句条件（选填）**：指定一个逻辑表达式，只有当该表达式的值为 True 时，遇到触发事件才会自动执行触发器指定的操作。

## 确认 SQL

完成 **<UI-TERM key="odc.components.TypePage.BasicInformation">基本信息</UI-TERM>** 和 **<UI-TERM key="src.component.Task.DataClearTask.CreateModal.85DFDA54">高级设置</UI-TERM>** 页签上所有信息的指定后，单击页面上 **<UI-TERM key="odc.component.CreateSynonymModal.NextConfirmTheSqlStatement">下一步：确认 SQL</UI-TERM>** 按钮以进入语句编辑页面。

在语句编辑页面中会根据 **<UI-TERM key="odc.components.SynonymPage.BasicInformation">基本信息</UI-TERM>** 和 **<UI-TERM key="odc.src.page.Datasource.Datasource.NewDatasourceDrawer.Form.ExtraConfig.AdvancedSettings">高级设置</UI-TERM>** 中指定的信息生成对应的触发器定义语句，您需要补齐语句中触发器触发后需执行的操作，即触发体。补齐触发体语句后，单击页面右上角的 **<UI-TERM key="odc.components.SQLConfirmPage.Create">创建</UI-TERM>** 按钮，完成触发器的创建。

同时，在编辑页面的工具栏中提供了以下功能键：

| 功能 | 说明 |
| --- | --- |
| 格式化 | 单击该按钮对选中的 SQL 语句或当前 SQL 窗口中的所有 SQL 语句进行统一的格式化（缩进、换行和高亮关键字等操作）。 |
| 查找/替换 | 在查找框内输入内容以对脚本进行检索，查找后可在替换框内输入内容以对查找内容进行替换。 |
| 撤销 | 将脚本回退到上一步操作执行的结果。 |
| 重做 | 执行 **<UI-TERM key="odc.EditorToolBar.actions.text.Revocation">撤销</UI-TERM>**  操作后，对脚本重新执行撤销前的操作。 |
| 大小写 | 提供 **<UI-TERM key="odc.EditorToolBar.actions.text.AllUppercase">全部大写</UI-TERM>** 、 **<UI-TERM key="odc.EditorToolBar.actions.text.AllLowercase">全部小写</UI-TERM>**  和 **<UI-TERM key="odc.EditorToolBar.actions.text.UppercaseLetters">首字母大写</UI-TERM>**  三种效果，将您在脚本中选中的语句转换为对应形式。 |
| 缩进 | 提供 **<UI-TERM key="odc.EditorToolBar.actions.text.AddIndentation">添加缩进</UI-TERM>**  和 **<UI-TERM key="odc.EditorToolBar.actions.text.DeleteIndentation">删除缩进</UI-TERM>**  两种效果，为您在脚本中选中的语句添加或删除包含的缩进。 |
| 注释 | 提供 **<UI-TERM key="odc.EditorToolBar.actions.text.AddComments">添加注释</UI-TERM>**  和 **<UI-TERM key="odc.EditorToolBar.actions.text.DeleteComments">删除注释</UI-TERM>**  两种效果，将您在脚本中选中的语句转换为注释或转换为 SQL 语句。 |
| 上一步 | 回到 **<UI-TERM key="odc.ResourceTree.actions.CreateATrigger">新建触发器</UI-TERM>** 页面，您可以继续编辑或修改 **<UI-TERM key="odc.components.TypePage.BasicInformation">基本信息</UI-TERM>** 和 **<UI-TERM key="src.component.Task.DataClearTask.CreateModal.85DFDA54">高级设置</UI-TERM>** 页签中的指定的值。 |
