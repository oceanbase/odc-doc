# 数据清理

本文档旨在介绍如何通过提交数据清理工单实现清理数据。

## 背景信息

ODC 支持在源数据库中的数据归档到目标数据库后，删除源数据库中的数据，以提高数据库查询性能，降低在线存储成本。

本文档以新建数据清理为例，介绍如何在 ODC 中清理数据库 test2 中的表 employee。

<main id="notice" type='explain'>
   <h4>说明</h4>
   <p>文中所使用的均为示例数据，您可根据实际情况对数据进行替换。</p>
</main>

## 注意事项

- 前置条件：

   - 清理的表中必须包含主键，若数据源类型为 OceanBase MySQL 及 MySQL，则包含唯一索引也可进行清理。

   - 用于清理的数据库用户需要拥有读/写权限和内部视图的访问权限。权限配置请参见 [查看用户权限](https://www.oceanbase.com/docs/enterprise-oceanbase-database-cn-10000000000945717)、[用户及权限概述](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000001574340) 和 [修改用户权限](https://www.oceanbase.com/docs/enterprise-oceanbase-database-cn-10000000000945718)。

- 清理数据源支持：

   - OceanBase MySQL 数据源。

   - OceanBase Oracle 数据源。

   - MySQL 数据源。

   - Oracle 数据源。

   - PostgreSQL 数据源。

- 以下情况不支持清理：

  - OceanBase MySQL 数据源若表中包含 XMLTYPE 字段类型，不支持清理。

  - OceanBase Oracle、Oracle 和 PostgreSQL 数据源若表中不包含主键 PRIMARY KEY，不支持清理。
  
  - OceanBase Oracle 数据源若表中包含 JSON、XMLTYPE 字段类型，不支持清理。

  - 若清理条件中包含 limit 语句，不支持清理。

  - 若表中包含外键，不支持清理。

## 新建数据清理

1. 在 SQL 开发窗口左侧导航栏的 **<UI-TERM key="odc.src.page.Workspace.ActivityBar.WorkOrder">工单</UI-TERM>** 页签中，单击 **<UI-TERM key="src.page.Workspace.SideBar.ResourceTree.TreeNodeMenu.config.51FA0E16">数据清理</UI-TERM>** > **<UI-TERM key="src.component.Task.DataClearTask.CreateModal.268C0069">新建数据清理</UI-TERM>**。

   <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/430/800.data-Lifecycle-management/200.data-cleanup/2.png" width="900">

3. 在 **<UI-TERM key="src.component.Task.DataClearTask.CreateModal.268C0069">新建数据清理</UI-TERM>** 页面中，输入以下信息。

   <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/433/800.data-Lifecycle-management/200.data-cleaning/3.png" width="900">

   |  信息项   |说明|
   |--------|-------|
   |清理前是否需要校验|勾选校验选项，清理前会检查待清理的表数据是否与目标表数据一致，如果数据一致则继续清理，否则不清理。|
   | 源端数据库    | 选择表所属的数据库。|
   |目标数据库|选择校验的表所属数据库。|
   | 清理范围 | <ul><li>部分清理：通过清理条件清理数据库中部分表。<ul><li>可使用常量或者引用变量配置中定义的变量来配置过滤条件。例如：`time<'${create_time}'`，其中 `create_time` 为变量配置中的变量名，`time` 为清理表中的字段。</li><li>勾选 **<UI-TERM key="src.component.Task.DataArchiveTask.DetailContent.5E7080E4">指定分区</UI-TERM>**，支持根据指定的分区清理数据。</li></ul></li><li>整库清理：清理数据库中所有表。</li></ul>|
   | 自定义变量  |可选项。通过定义变量和设置时间偏移量筛选表中符合条件的行进行清理。|
   |执行方式|选择 **<UI-TERM key="odc.components.TaskTimer.ExecuteNow">立即执行</UI-TERM>** / **<UI-TERM key="odc.components.TaskManagePage.ScheduledExecution">定时执行</UI-TERM>** / **<UI-TERM key="odc.src.component.Task.CycleExecution.1">周期执行</UI-TERM>** 设置任务执行方式。|
   |任务设置|配置限流策略。<ul><li>指定任务时长：任务启动指定时长后，若未完成则会暂停调度，等待下一次调度。</li><li>行限流：每秒操作数据总行限制。</li><li>**<UI-TERM> 搜索策略</UI-TERM>**：支持全表扫描和条件匹配。</li><li>数据大小限流：每秒操作数据总大小限制。</li><li>使用主键清理：选择是否使用主键清理数据。</li></ul>|
   | 备注   | 可在 **<UI-TERM key="odc.component.FormModal.Remarks">备注</UI-TERM>** 文本框中输入不超过 200 个字符的描述信息，该项为选填项。|                                             

3. 单击 **<UI-TERM key="src.component.Task.ApplyTablePermission.CreateModal.AB5C56FA">新建</UI-TERM>** 后，预览清理 SQL 语句并单击 **<UI-TERM key="odc.DataClearTask.CreateModal.Ok">确定</UI-TERM>**，完成新建数据清理。

   <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/433/800.data-Lifecycle-management/200.data-cleaning/4.png" width="400">

4. 任务生成后可以在 **<UI-TERM key="odc.src.page.Workspace.ActivityBar.WorkOrder">工单</UI-TERM>** > **<UI-TERM key="src.d.ts.CD43F08A">数据清理</UI-TERM>** 列表中查看/删除任务信息。
    
   <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/433/800.data-Lifecycle-management/200.data-cleaning/5.png" width="900">

## 查看数据清理任务

### 任务信息 

1. 如上图所示，在 **<UI-TERM key="odc.src.store.helper.page.pages.WorkOrder">工单</UI-TERM>** 的数据清理列表中，单击操作列中的 **<UI-TERM key="src.component.Task.component.CommonDetailModal.593D5BD8">查看</UI-TERM>** 按钮。

2. 在弹出的任务详情面板中，单击 **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskInformation">任务信息</UI-TERM>** 页签查看任务类型、源数据库、目标数据库、变量配置、清理范围和执行方式等信息。

   <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/433/800.data-Lifecycle-management/200.data-cleaning/6.png" width="900">
