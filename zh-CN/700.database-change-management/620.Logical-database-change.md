# 逻辑库变更管理

## 背景信息

ODC V4.3.2 及之后的版本支持对逻辑库中的数据进行变更。用户可以通过逻辑库变更任务运行耗时较高的 SQL 语句以避免语句执行超时。

<main id="notice" type='explain'>
   <h4>说明</h4>
   <ul>
   <li>如无逻辑库权限，您可以通过项目/工单中的 <strong>申请库权限</strong> 申请逻辑库权限。</li>
   <li>逻辑库与物理库关系等信息，请参见 <a href="200.project-collaborative-management.md">逻辑库管理</a>。</li>
   </ul>
</main>

## 注意事项

- 仅支持 OceanBase MySQL、MySQL 数据源。

- 仅支持 DDL 变更。

- 不支持 ODC 安全规范中的 SQL 检查规范及 SQL 窗口规范。

## 新建逻辑库变更任务

1. 在 **<UI-TERM key="odc.src.page.Auth.Autoauth.component.DetailContent.Project">项目</UI-TERM>**/**<UI-TERM key="odc.src.page.Workspace.ActivityBar.WorkOrder">工单</UI-TERM>** 中，单击 **<UI-TERM key="src.page.Workspace.SideBar.ResourceTree.TreeNodeMenu.config.11F98E6B">逻辑库变更</UI-TERM>**。

   - 通过项目入口创建逻辑库变更。

     <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/432/700.database-change-management/620.logical-database-change/1.png" width="900">

   - 通过工单入口创建逻辑库变更。

     <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/432/700.database-change-management/620.logical-database-change/2.png" width="900">

2. 在 **<UI-TERM key="src.component.Task.LogicDatabaseAsyncTask.CreateModal.6CD30B75">新建逻辑库变更</UI-TERM>** 页面中，输入以下信息。

   <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/432/700.database-change-management/620.logical-database-change/3.png" width="900">

   |  信息项   |说明|
   |--------|-------|
   | 逻辑库    | 选择需变更的逻辑库。|
   | SQL 内容 | 选择 **<UI-TERM key="odc.components.CreateAsyncTaskModal.SqlEntry">SQL 录入</UI-TERM>**：SQL 录入为默认方式，可在编辑区中直接录入 SQL 脚本。<main id="notice" type='explain'><h4>说明</h4><ul><li>在 SQL 录入中，最大允许输入 500000 个字符，如超限可上传附件。</li><li>单击 <strong><UI-TERM>IN 值转化</UI-TERM></strong> 按钮，可将批量复制的数据转化成 in（'A','B'）格式。</li><li>列值分隔符号为换行符。</li><li>行值分隔符为空格或 TAB 值。</li></ul></main>|
   | 分隔符    | 支持 Delimiter 分隔符号。|
   |任务设置|选择 **<UI-TERM key="odc.components.TaskManagePage.ExecuteNow">立即执行</UI-TERM>** / **<UI-TERM key="odc.components.TaskTimer.ScheduledExecution">定时执行</UI-TERM>** 设置任务执行方式。|
   | 执行超时时间 | 在 **<UI-TERM key="src.component.Task.MutipleAsyncTask.DetailContent.439EBA2B">执行超时时间</UI-TERM>** 文本框中输入数字指定语句执行超时时间，单位为小时（默认超时时间为 48 小时，最大不超过 480 小时）。|
   | 描述   | 可在 **<UI-TERM key="src.component.Task.LogicDatabaseAsyncTask.DetailContent.2376CB1E">任务描述</UI-TERM>** 文本框中输入不超过 200 个字符的描述信息，该项为选填项。|                                                    
3. 单击 **<UI-TERM key="odc.TreeNodeMenu.config.table.New">新建</UI-TERM>**，完成新建逻辑库变更。

4. 任务生成后可以在 **<UI-TERM key="odc.src.page.Workspace.ActivityBar.WorkOrder">工单</UI-TERM>** > **<UI-TERM key="src.component.Task.component.TaskTable.4203E912">逻辑库变更</UI-TERM>** 列表中查看任务信息。
    
    <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/432/700.database-change-management/620.logical-database-change/4.png" width="900">

## 查看逻辑库变更任务

### 任务信息 

1. 如上图所示，在 **<UI-TERM key="odc.src.page.Workspace.ActivityBar.WorkOrder">工单</UI-TERM>** 的逻辑库变更列表中，单击操作项下的 **<UI-TERM key="odc.Secure.MaskingAlgorithm.View">查看</UI-TERM>** 按钮。

2. 在弹出的任务详情面板中，单击 **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskInformation">任务信息</UI-TERM>** 页签查看所属逻辑库、任务类型、风险等级、SQL 内容等信息。

3. 单击 **<UI-TERM key="odc.TaskManagePage.component.TaskTools.InitiateAgain">再次发起</UI-TERM>**，可重新发起逻辑库变更任务。

    <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/432/700.database-change-management/620.logical-database-change/5.png" width="900">

### 任务流程 

在任务详情面板中，单击 **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskFlow">任务流程</UI-TERM>** 页签查看发起任务状态、审批状态、执行状态和执行结果等信息。

<img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/432/700.database-change-management/620.logical-database-change/6.png" width="900">

### 执行记录 

在任务详情面板中，单击 **<UI-TERM key="odc.component.CommonTaskDetailModal.ExecutionRecord">执行记录</UI-TERM>** 页签查看任务执行状态。

### 任务日志 

在任务详情面板中，单击 **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskLog">任务日志</UI-TERM>** 页签查看任务的全部日志和告警日志。

<img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/432/700.database-change-management/620.logical-database-change/7.png" width="900">

| 信息项  |  说明  |
|---------|--------------|
| 全部日志 | 全部日志显示任务的 **<UI-TERM>INFO</UI-TERM>**、**<UI-TERM>ERROR</UI-TERM>** 和 **<UI-TERM>WARN</UI-TERM>** 日志等全量信息。 单击 **<UI-TERM key="workspace.window.sql.button.search">查找</UI-TERM>**、**<UI-TERM key="odc.EditorToolBar.actions.script.Download">下载</UI-TERM>** 和 **<UI-TERM key="odc.component.Log.Copy">复制</UI-TERM>** 按钮，可查找信息、下载或复制全部日志信息。        |
| 告警日志 | 告警日志单独显示任务的 **<UI-TERM>ERROR</UI-TERM>** 和 **<UI-TERM>WARN</UI-TERM>** 日志。当任务失败时，可通过告警日志查看错误信息。 单击 **<UI-TERM key="workspace.window.sql.button.search">查找</UI-TERM>**、**<UI-TERM key="odc.components.TriggerPage.Download">下载</UI-TERM>** 和 **<UI-TERM key="odc.components.ConnectionCardList.Copy">复制</UI-TERM>** 按钮，可查找信息、下载或复制告警日志信息。 |
