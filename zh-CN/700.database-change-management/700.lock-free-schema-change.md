# 无锁结构变更

为解决变更数据库表结构时的锁表问题，ODC V4.2.0 及之后的版本提供了无锁结构变更功能，该功能可以较好地规避因锁表以致于阻塞业务。本文档旨在介绍如何通过提交无锁变更工单实现数据库无锁结构变更。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>无锁结构变更任务仅支持 OceanBase 数据库的 MySQL 模式，并且需要使用企业版或者社区版的 OMS。</p>
</main>

## 背景信息

### 原理介绍

无锁结构变更的原理是创建临时表，将原表数据拷贝到临时表中，将临时表结构变更，再全量拷贝数据到原表，最后切换新旧表。

无锁结构变更的执行过程如下图所示：

![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/sql-development/10.table%20structure%20change/1.png)

1. 创建临时表。

2. 变更临时表结构。

3. 全量拷贝数据。

4. 增量数据同步。

5. 数据一致性校验。

6. Kill Session。

7. 切换新旧表。


### 无锁结构变更工单执行流程

![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/sql-development/10.table%20structure%20change/2.png)

1. 用户提交无锁结构变更工单。

2. 对用户输入的 SQL 语句进行预检查。

3. 审批任务流程。

4. 执行无锁结构变更任务。

## 注意事项

- 确保数据库磁盘空间充足。

- 表中必须**存在主键或非空唯一键**且表中**不存在外键**。

- 当前表在执行无锁结构变更同时，执行其它 DDL 操作会导致任务失败。 

- OceanBase MySQL 模式下的表名称不超过 54 个字符。

- ODC 连接 OceanBase 社区版数据库时，数据源配置信息中需包含集群名和 SYS 租户账号。

- 默认通过锁定用户且关闭会话的方式避免表名切换过程中数据的写入，部分版本（OceanBase MySQL V4.2.5 及之后且 OceanBase MySQL V4.3.0 之前的版本）通过特定配置以 Lock Table 方式避免数据写入。具体配置请参见下文 新建无锁结构变更任务中的锁表配置。

- 无锁结构变更期间，发起其它关于该表的 DDL 变更将导致任务失败。


## 新建无锁结构变更任务

本文以 OceanBase 社区版和企业版 OMS 为例，演示场景为将表 student 中的列 birth 类型修改为 date。该示例所使用的项目名称为 odc_4.2.0，数据库名称为 odc_test，表名称为 student。

1. （可选）安装 OceanBase 社区版集群。如已完成集群配置，可跳过此步骤。

   <main id="notice" type='explain'>
      <h4>说明</h4>
      <p>通过企业版 OMS 创建 OceanBase 数据源时需包含集群名，单机无法创建数据源。具体部署集群的方法请参见 <a href="https://open.oceanbase.com/quickStart">方案二：部署 OceanBase 集群环境</a>。</p>
   </main>

2. [安装 ConfigServer](https://github.com/oceanbase/oceanbase/tree/master/tools/ob-configserver)。ConfigServer 为 OceanBase 和 OBProxy 存取 OceanBase rs_list 的接口, 完成配置 OceanBase ConfigServer 地址后，OceanBase 会自动注册 rs_list 到 ConfigServer。

   <main id="notice" type='explain'>
      <h4>说明</h4>
      <p>通过 OCP（非 OCP-express）部署集群时，可忽略此步骤。OCP 创建的集群会自动设置 OCP 的地址作为 OceanBase ConfigServer。</p>
   </main>

3. [安装企业版 OMS](https://www.oceanbase.com/docs/enterprise-oms-doc-cn-1000000000987946)。本文以企业版 OMS 为例，您可以通过 Docker 获取，您也可以按需选择社区版 OMS 并完成配置。

4. [部署 Web 版 ODC](../300.quickstart/200.web-odc-quickstart/200.quickstart-deployment-odc.md)。

5. 配置 ODC 元数据信息，启用无锁结构变更。

   a. ODC 配置企业版 OMS 信息。

      连接 ODC 的元数据库，配置企业版 OMS 的 URL 和登录授权信息。 oms_url 的构成为 `http://${oms_host}: ${oms_port}`，oms_authornazition 的构成为 `username:password` 的 Base64 编码。配置完成后，重启 ODC 使配置的企业版 OMS 信息生效。

      - 语法格式：

         ```shell
         #配置 oms_url
         update config_system_configuration set `value` = '${oms_url}' where `key` = 'odc.osc.oms.url';

         #配置 oms_authornazition
         update config_system_configuration set `value` = '${oms_authornazition}' where  `key` = 'odc.osc.oms.authorization';

         #配置 oms_region，例如 cn-anhui
         update config_system_configuration set value = '${oms_region}' where `key` = 'odc.osc.oms.region'
         ```

      - 示例：

         ```shell
         #配置 oms_url，填写 oms 的访问地址：http://localhost:8089
         update config_system_configuration set `value` = 'http://localhost:8089' where `key` = 'odc.osc.oms.url';

         #配置 oms_authornazition，如账户为 test，密码为 123456，将 `test:123456` 进行 Base64 编码后为：dGVzdDoxMjM0NTY=
         update config_system_configuration set `value` = 'dGVzdDoxMjM0NTY=' where `key` = 'odc.osc.oms.authorization';

         #配置 oms_region，如安装 oms 时输入的 region 为 cn-anhui，详情见 oms 安装过程
         update config_system_configuration set value = 'cn-anhui' where `key` = 'odc.osc.oms.region'
         ```

    b. 打开无锁结构变更。目前阿里云数据库 OceanBase 已开放无锁结构变更，而对于 OceanBase 社区版，ODC 默认未启用无锁结构变更，需要配置 ODC 元数据库，通过 SQL 语句打开配置。

       ```shell
       update config_system_configuration set value = 'true' where `key` = 'odc.features.task.osc.enabled';
       ```
6. [在 ODC 中创建和同步数据源](../400.connection-management/100.create-a-personal-connection.md)。

    <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>对于 OceanBase 社区版， 在使用 ODC 创建数据源时，需配置 sys 租户。<br><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/431/700.database-change-management/700.table-structure-change/2.2.png" width="200"></p>
    </main>

7. [创建项目并在项目中添加数据库](../300.quickstart/200.web-odc-quickstart/300.quickstart-using-web-odc.md)。

8. 在 SQL 窗口中，编辑 SQL 语句以创建表 student 到数据库 odc_test 中。

       <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/433/700.database-change-management/700.lock-free-schema-change/3.png" width="900">

      ```sql
      CREATE TABLE `odc_test`.`student` (
      `id` int(11) COMMENT 'student id' NOT NULL,
      `name` varchar(120) COMMENT 'student name' NULL,
      `birthday` datetime(0) COMMENT 'student birthday' NOT NULL,
      `province` varchar(120) COMMENT 'student province' NULL,
      `city` varchar(120) COMMENT 'student city' NULL,
      `mobile_phone` int COMMENT 'student mobile_phone' NULL,
      `email` varchar(120) COMMENT 'student email' NULL,
      `create_time` datetime(0) COMMENT 'update time' NULL,
      CONSTRAINT `cons_id` PRIMARY KEY (`id`)
      ) DEFAULT CHARSET = utf8mb4 COLLATE = utf8mb4_general_ci ;
      ```

9. 锁定账号/锁表。

   - 对于 OceanBasese MySQL V4.2.5 之前的版本，变更数据库表结构时不支持锁表，您需要指定将要锁定的账号，切换新旧表（`Rename`）时，ODC 会对锁定的账号执行 `alter table user lock account` 命令并关闭会话操作，以关闭锁定账号下的所有进程。
   
      <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/432/700.database-change-management/700.lock-free-schema-change/3.0.png" width="200">
      
   - 对于 OceanBase MySQL V4.2.5 及之后且 OceanBase MySQL V4.3.0 之前的版本，变更数据库表结构时不再通过锁定账号进行锁表，您需要确认 OBProxy 版本为 V4.3.1 及之后，并在无锁结构变更任务前执行以下操作进行锁表，否则锁表失败。
      
      1. 修改 OBProxy 参数。
      
         ```sql
         alter proxyconfig set proxy_id=1;
         alter proxyconfig set client_session_id_version=2;
         alter proxyconfig set enable_single_leader_node_routing = false;
         ```
         
      2. 修改租户级别参数。

         ```sql
         alter system set enable_lock_priority=true;
         ```
      
      3. 修改支持锁表功能的 OceanBase MySQL 版本范围。

         锁表功能默认支持的 OceanBase MySQL 版本范围为 V4.2.5 ~ V4.2.9。如需修改锁表功能支持的版本范围，您可以连接 ODC 的元数据库并执行如下 SQL 语句。
         
         ```sql
         insert into config_system_configuration( key, application, profile, label, description, value) values('odc.osc.support-lock-table-ob-version-json', 'odc', 'default', 'master', 'control odc enable lock table version, default is ["4\\.2\\.[5-9].* "]', '$期望版本范围');
         ```

         其中，`'$期望版本范围'` 为 JSON 数组，数组元素遵循 Java 通配规则。例如将 OceanBase MySQL 版本范围修改为 V4.2.5 ~ V4.2.9 以及 V4.3.5，其对应 value 值为 `["4\\\\.2\\\\.[5-9].*", "4.3.5.*"]`。

      4. 验证锁表是否成功，通过 ODC 执行 <code>lock table</code> 命令锁定一个临时表后，使用新链接尝试插入数据到临时表中，插入数据被阻塞则表示锁表任务生效。
      
         ```sql
         create table test_table(id int not null primary key);
         session 1:                                      session 2
         lock table test_table;
                                                         insert into test_table values(1);
                                                         阻塞中...
         unlock table test_table;                          
                                                         插入成功
         ```

10. 新建无锁结构变更任务。

    1. 在 **<UI-TERM key="odc.SideBar.Task.Ticket">工单</UI-TERM>** 页签中单击 **<UI-TERM key="odc.AlterDdlTask.DetailContent.LockFreeStructureChange">无锁结构变更</UI-TERM>** > **<UI-TERM key="odc.AlterDdlTask.CreateModal.NewLockFreeStructureChange">新建无锁结构变更</UI-TERM>**。

    2. 在 **<UI-TERM key="odc.AlterDdlTask.CreateModal.NewLockFreeStructureChange">新建无锁结构变更</UI-TERM>** 页面中，输入以下信息。

       <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/433/700.database-change-management/700.lock-free-schema-change/4.png" width="400">

       |  信息项   |说明|
       |--------|-------|
       | 数据库    | 选择需变更的数据库。|
       |锁定用户|<ul><li>如果指定锁定用户，则表名切换之前 ODC 会锁定所指定的数据库账号，并关闭该账号对应的所有会话信息，以保障表名切换期间数据一致性的同时尽可能降低对业务的影响。</li><li>如果未指定任何账号，ODC 将不会进行任何账号锁定及关闭会话操作，需自主确保切换期间数据的一致性。</li></ul><main id="notice" type='notice'><h4>注意</h4><p>执行无锁结构变更任务期间，执行该任务的用户不可执行与无锁结构变更相关表的变更操作。</p></main>|
       | 变更定义 | <ul><li>CREATE TABLE：OceanBasese 不支持的语法需要使用 CREATE 语句。</li><li>ALTER TABLE：OceanBasese V4.0.0 及之后的版本，ALTER TABLE OFFLINE 模式可以使用 ALTER 语句。</li></ul>  |
       | SQL 内容   | 在编辑区中录入 SQL 脚本。|
       | 切换表设置    | 数据一致后将原表切换为目标表。<ul><li>锁表超时时间：切换表过程会锁表，超时未切换完成可能导致执行失败。</li><li>失败重试次数：超过锁表时间后，未切换完成可自动重试。</li><li>完成后源表清理策略：选择 **<UI-TERM key="odc.AlterDdlTask.DetailContent.RenameNotProcessed">重命名不处理</UI-TERM>**，重命名源表，不删除。选择 **<UI-TERM key="odc.AlterDdlTask.CreateModal.DeleteNow">立即删除</UI-TERM>**，无锁结构变更完成后删除源表。</li></ul>|
       |任务设置|<ul><li> 选择 **<UI-TERM key="odc.components.TaskManagePage.ExecuteNow">立即执行</UI-TERM>**/**<UI-TERM key="odc.components.TaskManagePage.ScheduledExecution">定时执行</UI-TERM>**/**<UI-TERM key="src.component.Task.MutipleAsyncTask.CreateModal.A8CB0B6F">手动执行</UI-TERM>** 设置任务执行方式。</li><li>无锁结构变更工具提供两种任务错误处理方式：<ul><li> **<UI-TERM key="odc.TaskManagePage.AsyncTask.StopATask">停止任务</UI-TERM>**：停止任务为默认方式，运行脚本的过程中出现错误时会停止运行。</li><li> **<UI-TERM key="odc.ImportDrawer.ImportForm.IgnoreErrorsContinueTasks">忽略错误继续任务</UI-TERM>**：选择忽略错误继续任务方式，在运行脚本出现错后将跳过错误语句继续执行。</li></ul></li><li>选择 **<UI-TERM key="odc.src.component.Task.AlterDdlTask.DetailContent.AutomaticSwitch">自动切换</UI-TERM>**/**<UI-TERM key="odc.src.component.Task.AlterDdlTask.CreateModal.ManualSwitch">手动切换</UI-TERM>** 表名。|
       | 描述   | 可在 **<UI-TERM key="odc.SQLPlanTask.DetailContent.Description">描述</UI-TERM>** 文本框中输入不超过 200 个字符的描述信息，该项为选填项。|     

    3. 单击 **<UI-TERM key="odc.src.store.snippet.New">新建</UI-TERM>**，完成新建无锁结构变更。

## 查看无锁结构变更任务

### 查看任务信息 

1. 在无锁结构变更列表中，单击操作项下的 **<UI-TERM key="workspace.window.sql.explain.button.showOutputFilter">查看</UI-TERM>** 按钮。

2. 在弹出的任务详情面板中，单击 **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskInformation">任务信息</UI-TERM>** 页签查看所属数据库、任务类型、风险等级和 SQL 内容等信息。

3. 单击 **<UI-TERM key="odc.TaskManagePage.component.TaskTools.InitiateAgain">再次发起</UI-TERM>**，可重新发起无锁结构变更任务。

### 查看任务流程 

在任务详情面板中，单击 **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskFlow">任务流程</UI-TERM>** 页签查看发起任务状态、预检查、审批状态、执行状态和执行结果等信息。

### 查看执行记录 

在任务详情面板中，单击 **<UI-TERM key="workspace.window.sql.record.title">执行记录</UI-TERM>** 页签查看新表和源表 DDL，以及任务执行进度。

### 查看任务日志

在任务详情面板中，单击 **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskLog">任务日志</UI-TERM>** 页签查看任务的全部日志和告警日志。
