# 自动授权

本文档旨在介绍如何新建和管理自动授权规则。

## 背景信息

OceanBase 开发者中心（OceanBase Developer Center，ODC）支持拥有特殊权限的用户（系统管理员）定义自动授权规则。拥有该特殊权限的用户可以创建/修改/查看/停用自动授权规则。

自动授权是指对满足某些条件的用户，例如姓名、组织部门、登录方式等信息符合某些判断条件，在初次登录或创建用户时自动授予特定的角色或权限，以避免大量冗余授权操作的一项功能。

本文档以创建 grant system_admin for deptB 自动授权规则为例，memberOf.department 中的用户名包含 deptB 时，为该用户授予 system_admin 角色。

## 新建自动授权规则

1. 用户[在 ODC 上集成 OAuth2 且认证登录 ODC 后](../../1000.system-integration/100.login-integration.md)，OAuth2 授权系统返回数据结构。例如：

    ```json
    {
      "id": 1,
      "name": "username",
      "mail": "example@email.com",
      "memberOf": {
        "department": [
          {
            "name": "deptA",
            "description": "this is a department"
          },
          {
            "name": "deptB",
            "description": "this is a department"
          }
        ],
        "extra": "some other info"
      }
    }
    ```

    对于该数据，可以使用不同表达式获取对应的值。例如：

    | **expression**   | **result**           |
    |-------------|--------------|
    | id    | 1                    |
    | memberOf.department\[0\].name  |deptA   |
    | memberOf.department\[\*\].name |\["deptA", "deptB"\] |

2. 通过第三方登录 Web 版 ODC 后，在项目协同窗口的左侧导航栏中，单击 **<UI-TERM key="odc.page.Auth.UserPermissions">用户权限</UI-TERM>** > **授权规则** > **<UI-TERM key="odc.components.FormAutoAuthModal.CreateARule">新建规则</UI-TERM>**。

   <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/433/700.database-change-management/100.user-permission-and-management/200.manage-automatic-authorization-rules/1.0.png" width="400">

2. 在 **<UI-TERM key="odc.components.FormAutoAuthModal.CreateARule">新建规则</UI-TERM>** 面板中需指定以下信息以创建新的规则。

   <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/433/700.database-change-management/100.user-permission-and-management/200.manage-automatic-authorization-rules/2.0.png" width="900">

   | 信息项    | 说明|
   |--------|---------------|
   | 规则名称   | 指定该规则的名称，不可重名。 |
   | 状态     | 选择 **<UI-TERM key="odc.components.SensitiveRule.Enable">启用</UI-TERM>** / **<UI-TERM key="odc.component.DetailContent.Disable">停用</UI-TERM>** 该授权规则。<br> 规则状态默认为 **<UI-TERM key="odc.components.RolePage.Enable">启用</UI-TERM>**，可手动更改为 **<UI-TERM key="odc.component.FormModal.Disable">停用</UI-TERM>** 。被停用的规则将不能被访问。 |
   | 触发事件   | 当前只能选择系统内置的事件，不同事件对应不同的触发时机。|
   | 匹配条件（可选）   | 单击 **<UI-TERM key="odc.src.page.Auth.Autoauth.component.FormModal.AddTo">添加</UI-TERM>**  按钮并指定以下四个字段创建匹配条件。<ul><li> **<UI-TERM key="odc.components.TypePage.Object">对象</UI-TERM>**：存储了触发条件和执行行为所需的信息，可以为复杂嵌套对象，包括 array、list 和 map；也可以为字符串和数字等简单对象。 </li><li> **<UI-TERM key="src.page.Project.Database.components.LogicDatabase.B79AD693">表达式</UI-TERM>**：目标在对象中所处的索引，不同类型对象的索引方式有区别。 </li><li> **<UI-TERM key="odc.components.RecordPage.Actions">操作</UI-TERM>**：支持包含、匹配和等于操作。 </li><li> **<UI-TERM key="odc.components.PLDebugResultSet.Value">值</UI-TERM>**：目标值。<main id="notice" type='explain'><h4>说明</h4><ul><li>如未选择添加匹配条件，表示触发选择的事件则会无条件执行动作。</li><li>选择 <strong>匹配</strong> 作为匹配条件时，匹配值需为正则表达式。</li></ul></main>|
   | 执行动作（可选）   | 选择 **<UI-TERM key="odc.components.AutoAuthPage.GrantRoles">授予角色</UI-TERM>** / **<UI-TERM key="odc.src.page.Auth.Autoauth.component.DetailContent.AwardedProjectRole">授予项目角色</UI-TERM>** 并配置对应的角色名称/项目角色名称。<main id="notice" type='explain'><h4>说明</h4><p>如未选择执行动作，表示无论是否满足匹配条件均不执行任何动作。</p></main> |
   | 备注（可选） | 为规则添加备注信息，非必填项。|

3. 指定上述信息后，单击面板右下角的 **<UI-TERM key="odc.components.RecordPage.Create">新建</UI-TERM>** 按钮以完成创建规则。

4. 创建完成后，可在自动授权列表中查看创建的规则。

   <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/433/700.database-change-management/100.user-permission-and-management/200.manage-automatic-authorization-rules/3.0.png" width="900">


## 查看自动授权规则

### 自动授权规则列表

如上图所示，在自动授权规则列表中显示并提供了以下基本信息。

| 信息项  | 说明|
|--------|-----------|
| 规则名称 | 显示规则的名称信息。  |
| 创建人  | 显示创建发起人。<br> 单击搜索图标![搜索](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/icon/search.jpg)，可搜索和筛选创建人。  |
| 状态   | 显示规则当前状态：**<UI-TERM key="odc.components.RolePage.component.Enable">启用</UI-TERM>** 或者 **<UI-TERM key="odc.components.CommonStatus.Disable">停用</UI-TERM>** 。<br> 单击筛选图标![筛选](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/icon/filter.jpg)，可筛选状态。 |
| 创建时间 | 显示对规则进行 **<UI-TERM key="src.component.Task.MutipleAsyncTask.components.Template.E0648BE6">编辑</UI-TERM>** 的最新历史操作时间。<br> 支持以升序或降序方式显示创建时间。   |
|启用|支持启用/停用规则。|
| 操作   | 支持 **<UI-TERM key="odc.component.RecordPopover.components.View">查看</UI-TERM>** 、 **<UI-TERM key="odc.ResourceTree.config.treeNodesActions.Editing">编辑</UI-TERM>** 和 **<UI-TERM key="odc.TreeNodeMenu.config.sequence.Delete">删除</UI-TERM>** 规则。 |


### 查看规则

<img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/433/700.database-change-management/100.user-permission-and-management/200.manage-automatic-authorization-rules/4.0.png" width="400">

在自动授权规则信息 **<UI-TERM key="odc.components.UserPage.Operation">操作</UI-TERM>** 栏下，单击 **<UI-TERM key="odc.components.RecordPage.View">查看</UI-TERM>** 按钮以弹出 **<UI-TERM key="odc.components.AutoAuthPage.RuleInformation">规则信息</UI-TERM>** 面板。面板中包括以下信息。

| 信息项  | 说明  |
|--------|---------|
| 规则信息 | 显示 **<UI-TERM key="odc.components.FormAutoAuthModal.RuleName">规则名称</UI-TERM>**、**<UI-TERM key="odc.components.FormAutoAuthModal.TriggerEvent">触发事件</UI-TERM>**、**<UI-TERM key="odc.components.AutoAuthPage.component.MatchingCondition">匹配条件</UI-TERM>**、**<UI-TERM key="odc.components.AutoAuthPage.component.PerformAnAction">执行动作</UI-TERM>**、**<UI-TERM key="src.page.Datasource.Datasource.NewDatasourceDrawer.Form.Account.C21B3C92">角色</UI-TERM>**、**<UI-TERM key="odc.src.page.Auth.Autoauth.component.FormModal.AwardedProjectRole">授予项目角色</UI-TERM>** 和 **<UI-TERM key="odc.component.DetailContent.Remarks">备注</UI-TERM>** 等创建规则时所指定的信息。 |
| 操作信息 | 显示 **<UI-TERM key="odc.AlterDdlTask.DetailContent.Founder">创建人</UI-TERM>**、**<UI-TERM key="odc.ExternalIntegration.SqlInterceptor.CreationTime">创建时间</UI-TERM>** 和 **<UI-TERM key="odc.components.RolePage.component.UpdateTime">更新时间</UI-TERM>** 等信息。  |

### 编辑规则

<img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/433/700.database-change-management/100.user-permission-and-management/200.manage-automatic-authorization-rules/5.0.png" width="900">

在自动授权规则信息 **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskRecord.Operation">操作</UI-TERM>** 栏下，单击 **<UI-TERM key="odc.components.SensitiveColumn.Edit">编辑</UI-TERM>** 按钮以弹出 **<UI-TERM key="odc.components.FormAutoAuthModal.EditRule">编辑规则</UI-TERM>** 面板。

**<UI-TERM key="odc.components.FormAutoAuthModal.EditRule">编辑规则</UI-TERM>** 面板中显示新建规则时所指定的所有信息项，可修改此类信息项以编辑规则。

### 删除规则

在自动授权规则信息 **<UI-TERM key="src.page.Project.Notification.components.89B6BD2A">操作</UI-TERM>** 栏下，单击 **<UI-TERM key="odc.TableConstraint.Primary.Delete">删除</UI-TERM>** 按钮删除创建的规则。
