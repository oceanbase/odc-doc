# 结构比对

## 背景信息

ODC 的结构比对功能支持将同一项目下、同类型数据源的数据库对象结构进行对比分析，并生成变更脚本。

本文档旨在介绍如何通过 ODC 提交结构比对工单以对比分析两个数据库对象结构。

本文档以创建结构比对为例，介绍如何将同一项目中的两个 OceanBase MySQL 数据源下的 employee 表结构进行对比。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <p>文中所使用的均为示例数据，您可根据实际情况对数据进行替换。</p>
</main>

## 注意事项

- 链路支持：

  - OceanBase MySQL 到 OceanBase MySQL。
  - OceanBase Oracle 到 OceanBase Oracle。
  - MySQL 到 MySQL。

- 仅支持比对表对象，比对属性范围仅包含列、主键、约束、索引、分区、表属性。

  - 关于列属性，仅支持比对类型、字符集、排序规则、注释、缺省值。

  - 关于分区，仅支持比对一级分区不支持比对二级分区。

  - 关于表属性，仅支持比对字符集、排序规则、注释。

- OceanBase MySQL 不支持比对检查约束。

- OceanBase MySQL V1.4.79 之前版本，如果没有 sys 租户查询权限，不支持对比分区属性。 

- 若生成的总的 SQL 变更脚本的文件大小大于 1 MB，则不会直接在 **<UI-TERM key="odc.StructConfigPanel.StructAnalysisResult.SqlPreview">SQL 预览</UI-TERM>** 显示内容，而是提示用户文件内容超过最大限制，只能通过 **<UI-TERM key="src.component.Task.component.ActionBar.DBA6CB6E">下载 SQL</UI-TERM>** 来查看总的变更脚本内容。 

## 执行流程

![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/900.structural-comparison/1.png)

1. 用户发起结构比对工单。
  
2. 审批任务流程。

3. 执行结构比对任务，并展示结构比对结果。

4. 新建数据库变更任务以同步结构。

## 新建结构比对

1. 在 **<UI-TERM key="odc.SideBar.Task.Ticket">工单</UI-TERM>** 页签中单击 **<UI-TERM key="src.component.Task.component.TaskTable.80E1D16A">结构比对</UI-TERM>** > **<UI-TERM key="src.component.Task.StructureComparisonTask.CreateModal.45DB3909">新建结构比对</UI-TERM>**。

   ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/900.structural-comparison/2.png)

2. 在 **<UI-TERM key="src.component.Task.StructureComparisonTask.CreateModal.45DB3909">新建结构比对</UI-TERM>** 页面中，输入以下信息。

   ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/900.structural-comparison/3.png)

   |  信息项   |说明|
   |--------|-------|
   | 源端数据库    | 选择源端数据库。|
   | 目标端数据库    | 选择需比对的数据库。|
   | 比对范围 | 支持选择 **<UI-TERM key="odc.CreateShadowSyncModal.SelectPanel.PartialTable">部分表</UI-TERM>** 或者 **<UI-TERM key="odc.CreateShadowSyncModal.SelectPanel.AllTables">全部表</UI-TERM>**：<ul><li> **<UI-TERM key="odc.CreateShadowSyncModal.SelectPanel.PartialTable">部分表</UI-TERM>**：在 **对比对象** 的 **<UI-TERM key="odc.CreateShadowSyncModal.SelectPanel.SelectSourceTable">选择源表</UI-TERM>** 窗口中勾选需要比对的对象。 </li><li>**<UI-TERM key="src.component.Task.StructureComparisonTask.CreateModal.9C98407E">全部表</UI-TERM>**：比对源端数据库和目标端数据库的所有表对象。</li></ul>      |
   |任务设置|**<UI-TERM key="src.component.Task.MutipleAsyncTask.CreateModal.D0E2C00B">自动执行</UI-TERM>** 任务。|
   | 描述   | 可在 **<UI-TERM key="odc.src.component.Task.AsyncTask.DetailContent.MissionDetails">任务描述</UI-TERM>** 文本框中输入不超过 200 个字符的描述信息，该项为选填项。|  
                                
3. 单击 **<UI-TERM key="workspace.header.create">新建</UI-TERM>**，完成新建结构比对。

4. 任务生成后可以在 **<UI-TERM key="odc.SideBar.Task.Ticket">工单</UI-TERM>** > **<UI-TERM key="src.constant.C180952A">结构比对</UI-TERM>** 列表中查看任务信息。
    
    ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/900.structural-comparison/4.png)

5. 如上图所示，单击 **<UI-TERM key="odc.SensitiveColumn.components.ScanForm.Operation">操作</UI-TERM>** 项下的 **<UI-TERM key="odc.components.AutoAuthPage.View">查看</UI-TERM>** 按钮，查看结构比对详情。

   ![5.1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/900.structural-comparison/5.1.png)

6. 单击 **<UI-TERM key="src.component.Task.component.ActionBar.46F2F0ED">发起结构同步</UI-TERM>** 发起数据库变更任务。

   ![5.2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/900.structural-comparison/5.2.png)

   ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/900.structural-comparison/4.png)

2. 在弹出的任务详情面板中，单击 **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskInformation">任务信息</UI-TERM>** 页签查看任务基本信息和设置信息。

   ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/900.structural-comparison/5.png)

3. 在任务信息面板右下角，单击 **<UI-TERM key="src.component.Task.component.ActionBar.46F2F0ED">发起结构同步</UI-TERM>**/**<UI-TERM key="odc.TaskManagePage.component.TaskTools.InitiateAgain">再次发起</UI-TERM>**/**<UI-TERM key="src.component.Task.component.ActionBar.DBA6CB6E">下载 SQL</UI-TERM>**，可以新建数据库变更/重新发起任务/下载 SQL 变更脚本。
