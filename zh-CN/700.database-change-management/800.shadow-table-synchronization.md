# 影子表同步

## 背景信息

ODC 的影子表同步功能支持根据源表的表结构自动在当前库中创建影子表（表名是在源表名上增加前缀或后缀的方式生成），适用于全链路压测等场景。

本文档以创建影子表为例，介绍如何在数据库 odc_test 中创建影子表 employee_t。

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul>
  <li>文中所使用的均为示例数据，您可根据实际情况对数据进行替换。</li>
  <li>ODC V4.0.0 及之后版本的影子表同步功能仅支持 MySQL 模式，且如果源表中包含二级分区，仅支持 HASH/KEY 的二级模板分区。</li>
  <li>影子表创建完成后，可以在表对象列表中查看创建的影子表。</li>
  <li>创建影子表时，如果表名已存在但表结构不同，则会生成同步 SQL 语句，更新影子表结构。</li>
  </ul>
</main>

## 新建影子表同步

1. 在 SQL 开发窗口的 **<UI-TERM key="odc.src.store.helper.page.pages.WorkOrder">工单</UI-TERM>** 页签中单击 **<UI-TERM key="src.page.Workspace.SideBar.ResourceTree.TreeNodeMenu.config.1ACCD0B1">影子表同步</UI-TERM>** > **<UI-TERM key="odc.components.CreateShadowSyncModal.CreateAShadowTableSynchronization">新建影子表同步</UI-TERM>**。

   <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/433/700.database-change-management/800.shadow-table-synchronization/1.png" width="200">

2. 在 **<UI-TERM key="odc.components.CreateShadowSyncModal.CreateAShadowTableSynchronization">新建影子表同步</UI-TERM>** 面板中指定以下信息。

   1. 选择对象。

      <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/433/700.database-change-management/800.shadow-table-synchronization/2.png" width="900">

      | **信息项** | **说明**   |
      |---------|------------|
      | 数据库     | 选择创建影子表的所属库并可查看当前数据源名称。 |
      | 同步范围    | 选择需要同步的表：<ul> <li> **<UI-TERM key="odc.CreateShadowSyncModal.SelectPanel.PartialTable">部分表</UI-TERM>**：选定的表在当前库中创建影子表。单击搜索框左侧的全选框，支持全选源表。 </li><li>  **<UI-TERM key="odc.CreateShadowSyncModal.SelectPanel.AllTables">全部表</UI-TERM>**：来源库中所有的表都会在当前库中创建影子表。 </li></ul>  |
      | 影子表名    | 支持以" **<UI-TERM key="src.component.Task.component.PartitionPolicyFormTable.7D91EBA7">前缀</UI-TERM>** +源表名"或"源表名+ **<UI-TERM key="src.component.Task.component.PartitionPolicyFormTable.0F79EE9C">后缀</UI-TERM>** "的格式创建影子表名，并且支持自定义前、后缀。    |
      | 同步对象    | 同步部分表时，需在 **<UI-TERM key="odc.CreateShadowSyncModal.SelectPanel.SynchronizeObjects">同步对象</UI-TERM>** 中选择源表以同步为影子表。   |

   2. 单击下一步进行同步影子表结构分析。

      <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/433/700.database-change-management/800.shadow-table-synchronization/3.png" width="900">

      | **信息项** | **说明** |
      |---------|-----------------|
      | 同步的表    | **<UI-TERM key="odc.StructConfigPanel.StructAnalysisResult.SynchronizedTables">同步的表</UI-TERM>** 页签中，显示源表名、影子表名和分析结果，单击 **<UI-TERM key="odc.components.UserPage.See">查看</UI-TERM>** 支持查看源表结构、影子表结构和结构变更 SQL 语句，单击 **<UI-TERM key="odc.StructConfigPanel.StructAnalysisResult.column.Skip">跳过</UI-TERM>** 支持不同步该影子表。  |
      | 不同步的表   | **<UI-TERM key="odc.StructConfigPanel.StructAnalysisResult.UnsynchronizedTables">不同步的表</UI-TERM>** 页签中，显示源表名、影子表名和分析结果，单击 **<UI-TERM key="odc.StructConfigPanel.StructAnalysisResult.column.CancelSkip">取消跳过</UI-TERM>** 支持同步该影子表。<main id="notice" type='explain'><h4>说明</h4><p> 选择跳过同步的表，会显示在 **<UI-TERM key="odc.StructConfigPanel.StructAnalysisResult.UnsynchronizedTables">不同步的表</UI-TERM>** 页签中。</br> 如果影子表名已存在且结构与源表一致，则会自动跳过同步表结构。</p></main> |
      | SQL 预览  | 显示同步表结构的 SQL 语句。   |
      | 任务设置    | <ul><li>选择审批完成后的 **<UI-TERM key="src.component.Task.LogicDatabaseAsyncTask.DetailContent.E2799F2E">执行方式</UI-TERM>** 。<ul><li> **立即同步**：立即执行同步任务。 </li><li> **定时同步**：定时执行同步任务。</li></ul></li><li> 选择 **<UI-TERM key="odc.AlterDdlTask.DetailContent.TaskErrorHandling">任务错误处理</UI-TERM>** 方式。<ul><li> **<UI-TERM key="odc.TaskManagePage.AsyncTask.StopATask">停止任务</UI-TERM>**：在执行过程中，遇到出错则中断后面的 SQL 脚本，不再执行。 </li><li> **<UI-TERM key="src.component.Task.MutipleAsyncTask.CreateModal.6E9057B6">忽略错误继续执行</UI-TERM>**：在执行过程中，跳过当前出错的 SQL 脚本继续执行，并执行完所有 SQL 脚本。</li></ul></li></ul>  |
      | 描述      | 描述项目的业务背景信息，例如变更目的、预期目标等。  |

4. 指定上述信息后，单击面板右下角的 **<UI-TERM key="odc.SensitiveRule.components.FormSensitiveRuleDrawer.Submit">提交</UI-TERM>** 按钮完成创建影子表同步任务。

5. 任务生成后会自动弹出 **<UI-TERM key="odc.component.TaskPopover.TaskCenter">任务中心</UI-TERM>** 面板，在任务中心可以查看任务审批状态和任务信息。

   <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/433/700.database-change-management/800.shadow-table-synchronization/4.png" width="900">

## 查看影子表同步任务

### 任务信息

1. 在 **<UI-TERM key="odc.component.VersionModal.newVersionConfig.TaskCenter">任务中心</UI-TERM>** 的影子表同步列表中，单击列表操作列中的 **<UI-TERM key="odc.components.PLTable.View">查看</UI-TERM>** 按钮。

2. 在弹出的任务详情面板中，单击 **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskInformation">任务信息</UI-TERM>** 页签查看任务基本信息和设置信息。

3. 在任务信息面板右下角，单击 **<UI-TERM key="src.component.Task.component.ActionBar.C324AD20">再次发起</UI-TERM>**，可以重新发起任务。

### 任务流程

1. 在弹出的任务详情面板中，单击 **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskFlow">任务流程</UI-TERM>** 页签查看 **发起任务状态**、**<UI-TERM key="odc.component.CommonTaskDetailModal.TaskOperationRecord.ApprovalStatus">审批状态</UI-TERM>**、**<UI-TERM key="src.component.Task.component.CommonDetailModal.B46A5216">执行状态</UI-TERM>** 和 **完成结果** 等信息。

2. 在面板右下角，单击 **<UI-TERM key="odc.TaskManagePage.component.TaskTools.InitiateAgain">再次发起</UI-TERM>**，可重新发起任务。

### 任务日志 

1. 在任务详情面板中，单击 **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskLog">任务日志</UI-TERM>** 标签查看任务的全部日志和告警日志。

   | 信息项  | 说明  |
   |------|-----------------------------------------------------------------------------------------------------------------------------|
   | 全部日志 | 全部日志显示任务的 **<UI-TERM>INFO**、**<UI-TERM>ERROR** 和 **<UI-TERM>WARN** 日志等全量信息。<br> 单击 **<UI-TERM key="workspace.window.sql.button.search">查找</UI-TERM>**、**<UI-TERM key="odc.TaskManagePage.component.TaskTools.Download">下载</UI-TERM>** 和 **<UI-TERM key="src.component.ExecuteSqlDetailModal.68BF8995">复制</UI-TERM>** 按钮，可查找信息、下载或复制全部日志信息。        |
   | 告警日志 | 告警日志单独显示任务的 **ERROR** 和 **WARN** 日志。当任务失败时，可通过告警日志查看错误信息。<br> 单击 **<UI-TERM key="workspace.window.sql.button.search">查找</UI-TERM>**、**<UI-TERM key="odc.components.TypePage.Download">下载</UI-TERM>** 和 **<UI-TERM key="odc.components.ConnectionCardList.Copy">复制</UI-TERM>** 按钮，可查找信息、下载或复制告警日志信息。 |

2. 单击 **<UI-TERM key="odc.TaskManagePage.component.TaskTools.InitiateAgain">再次发起</UI-TERM>**，可重新发起任务。
