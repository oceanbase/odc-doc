# 数据库变更管理

## 背景信息

ODC 支持对数据库中的数据进行变更。用户可以通过数据库变更任务运行耗时较高的 SQL 语句以避免语句执行超时。

## 注意事项

- 只支持对 UPDATE 和 DELETE 变更语句自动生成回滚语句。

- 支持的变更影响行数上限为 100W，超过则不支持自动生成回滚语句。

- 若表中包含大字段，不支持自动生成回滚语句。

- OceanBase MySQL、MySQL 数据源下，若表中无主键或者唯一键，不支持自动生成回滚语句。

- UPDATE 语句的修改字段（Set）和条件字段（Where）相同，不支持自动生成回滚语句。

- 最大支持生成的自动回滚语句脚本大小为 256MB。

## 新建数据库变更任务

示例：将数据库 odc_test 中表 employee 的 name 值 xiaoguo 修改为 xiaofeng。

| 信息项 | 示例值 |
| ------ | ------ |
|项目名称 | odc_4.2.0 |
|所属数据源|mysql420 |
|数据库名称|odc_test|
|表名称|employee|

1. 在 **<UI-TERM key="odc.src.component.Task.ApplyPermission.CreateModal.Project">项目</UI-TERM>** > **<UI-TERM key="odc.Project.Project.AllProjects">全部项目</UI-TERM>** 页面中单击项目名称 **odc_4.2.0**。

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/quickstart/webodc/add%20database/1.png)

2. 在 **<UI-TERM key="odc.page.Task.Ticket">工单</UI-TERM>** 页签中单击 **<UI-TERM key="odc.PermissionApplication.CreateModal.DatabaseChanges">数据库变更</UI-TERM>** > **<UI-TERM key="src.component.Task.AsyncTask.CreateModal.6EEFAEA6">新建数据库变更</UI-TERM>**。

   ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/420/quickstart/webodc/create%20database%20change/2.png)

3. 在 **<UI-TERM key="src.component.Task.AsyncTask.CreateModal.6EEFAEA6">新建数据库变更</UI-TERM>** 页面中，输入以下信息。

   ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/600.database-change/3.png)

   |  信息项   |说明|
   |--------|-------|
   | 数据库    | 选择需变更的数据库。|
   | SQL 内容 | 选择 **<UI-TERM key="src.component.Task.LogicDatabaseAsyncTask.CreateModal.0A3EB502">SQL 录入</UI-TERM>** 或 **<UI-TERM key="src.component.Task.MutipleAsyncTask.CreateModal.447DDBF6">上传附件</UI-TERM>** ：<ul><li> **<UI-TERM key="src.component.Task.MutipleAsyncTask.CreateModal.F79FDCAD">SQL 录入</UI-TERM>** ：SQL 录入为默认方式，可在编辑区中直接录入 SQL 脚本。<main id="notice" type='explain'><h4>说明</h4><ul><li>在 SQL 录入中，最大允许输入 500000 个字符，如超限可上传附件。</li><li>单击 <strong>IN 值转化</strong> 按钮，可将批量复制的数据转化成 in（'A','B'）格式。</li><li>列值分隔符号为换行符。</li><li>行值分隔符为空格或 TAB 值。</li></ul></main> </li><li> **<UI-TERM key="odc.components.CreateSQLPlanTaskModal.UploadAnAttachment">上传附件</UI-TERM>** ：选择上传附件方式后，单击文件池进入文件资源管理器选择要导入的文件或者直接将导入文件拖入文件池中以完成文件上传。<main id="notice" type='explain'><h4>说明</h4><ul><li>最多支持上传 500 个文件，总文件大小不超过 256 MB。</li><li>默认附件按上传的先后排序，可拖拽改变顺序，任务执行时按文件顺序执行。</li><li>当前只支持上传 .sql 后缀的 SQL 文件。</li></ul></main> </li></ul>      |
   |SQL 检查|单击该按钮检查 SQL 语法。|
   | 回滚方案   | 指定 **<UI-TERM key="odc.components.CreateAsyncTaskModal.RollbackScheme">回滚方案</UI-TERM>** 。 回滚方案支持 SQL 文本录入及上传附件方式，参见 **<UI-TERM key="src.component.Task.LogicDatabaseAsyncTask.CreateModal.844AC838">SQL 内容</UI-TERM>** 信息。<main id="notice" type='explain'><h4>说明</h4><p>勾选 <strong>生成备份回滚方案</strong>， 支持对 UPDATE/DELETE 语句自动生成备份回滚 SQL。</p><ul><li>OceanBase MySQL 和 MySQL 模式下，自动生成备份回滚方案仅支持对包含主键或者唯一键的表进行 UPDATE/DELETE 时生成对应回滚 SQL。</li><li>自动生成备份回滚方案支持的单条变更 SQL 的影响行数不超过 10w 行，数据库变更的总影响行数不超过 100w 行。</li></ul></main>|
   | 分隔符    | 支持 Delimiter 分隔符号。|
   | 查询结果限制 | 支持设置查询结果限制 (1-100w)。 |
   |任务设置|<ul><li> **<UI-TERM key="src.component.Task.AsyncTask.DetailContent.1F4ECA8A">SQL 重试次数</UI-TERM>**：重试次数大于 1，表示 SQL 语句执行失败后，ODC 会在三分钟后重新执行该 SQL 语句。</li><li>数据库变更工具提供两种任务错误处理方式：<ul><li> **<UI-TERM key="odc.components.CreateAsyncTaskModal.StopATask">停止任务</UI-TERM>** ：停止任务为默认方式，运行脚本的过程中出现错误时会停止运行。</li><li> **<UI-TERM key="odc.components.CreateSQLPlanTaskModal.IgnoreErrorsToContinueThe">忽略错误继续任务</UI-TERM>** ：选择忽略错误继续任务方式，在运行脚本出现错后将跳过错误语句继续执行。</li></ul></li><li> 选择 **<UI-TERM key="odc.components.TaskTimer.ExecuteNow">立即执行</UI-TERM>** / **<UI-TERM key="odc.components.TaskTimer.ScheduledExecution">定时执行</UI-TERM>** 设置任务执行方式。</li></ul>|
   | 执行超时时间 | 在 **<UI-TERM key="src.component.Task.PartitionTask.CreateModal.59540029">执行超时时间</UI-TERM>** 文本框中输入数字指定语句执行超时时间，单位为小时（默认超时时间为 48 小时，最大不超过 480 小时）。|
   | 描述   | 可在 **<UI-TERM key="odc.src.component.Task.ResultSetExportTask.DetailContent.MissionDetails">任务描述</UI-TERM>** 文本框中输入不超过 200 个字符的描述信息，该项为选填项。|                                                    
3. 单击 **<UI-TERM key="odc.DataArchiveTask.CreateModal.Create">新建</UI-TERM>**，完成新建数据库变更。

4. 任务生成后可以在 **<UI-TERM key="odc.SideBar.Task.Ticket">工单</UI-TERM>** > **<UI-TERM key="odc.components.TaskManagePage.DatabaseChanges">数据库变更</UI-TERM>** 列表中查看任务信息。
    
    ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/600.database-change/4.png)

## 查看数据库变更任务

### 任务信息 

1. 如上图所示，在 **<UI-TERM key="odc.src.page.Workspace.ActivityBar.WorkOrder">工单</UI-TERM>** 的数据库变更列表中，单击操作项下的 **<UI-TERM key="src.page.Project.Notification.components.445FB17E">查看</UI-TERM>** 按钮。

2. 在弹出的任务详情面板中，单击 **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskInformation">任务信息</UI-TERM>** 页签查看所属数据库、任务类型、风险等级、SQL 内容和回滚内容等信息。

    <main id="notice" type='explain'>
       <h4>说明</h4>
       <p>单击 <strong>下载备份回滚方案</strong>，支持下载 ODC 对 UPDATE/DELETE 语句自动生成的备份回滚方案文件。</p>
    </main>

    ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/600.database-change/5.png)

3. 单击 **<UI-TERM key="odc.TaskManagePage.component.TaskTools.InitiateAgain">再次发起</UI-TERM>**，可重新发起数据库变更任务；单击 **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskFlow.RollBack">回滚</UI-TERM>**，回滚数据。

### 任务流程 

![6](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/600.database-change/6.png)

在任务详情面板中，单击 **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskFlow">任务流程</UI-TERM>** 页签查看发起任务状态、审批状态、执行状态和执行结果等信息。


### 执行结果 

![7](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/600.database-change/7.png)

### 回滚工单

在任务详情面板中，单击 **<UI-TERM key="odc.component.CommonDetailModal.RollbackTicket">回滚工单</UI-TERM>** 查看任务


### 任务日志 

![8](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/424/700.database-change-management/600.database-change/8.png) 

在任务详情面板中，单击 **<UI-TERM key="odc.component.CommonTaskDetailModal.TaskLog">任务日志</UI-TERM>** 页签查看任务的全部日志和告警日志。


| 信息项  |  说明  |
|---------|--------------|
| 全部日志 | 全部日志显示任务的 **<UI-TERM>INFO</UI-TERM>**、**<UI-TERM>ERROR</UI-TERM>** 和 **<UI-TERM>WARN</UI-TERM>** 日志等全量信息。 单击 **<UI-TERM key="workspace.window.sql.button.search">查找</UI-TERM>**、**<UI-TERM key="odc.components.FunctionPage.Download">下载</UI-TERM>** 和 **<UI-TERM key="odc.TaskManagePage.component.TaskTools.Copy">复制</UI-TERM>** 按钮，可查找信息、下载或复制全部日志信息。        |
| 告警日志 | 告警日志单独显示任务的 **<UI-TERM>ERROR</UI-TERM>** 和 **<UI-TERM>WARN</UI-TERM>** 日志。当任务失败时，可通过告警日志查看错误信息。 单击 **<UI-TERM key="workspace.window.sql.button.search">查找</UI-TERM>**、**<UI-TERM key="odc.components.TriggerPage.Download">下载</UI-TERM>** 和 **<UI-TERM key="src.component.ExecuteSqlDetailModal.68BF8995">复制</UI-TERM>** 按钮，可查找信息、下载或复制告警日志信息。 |
