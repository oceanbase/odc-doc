# 操作审计

## 背景信息

支持查看和导出您在 ODC 上的操作历史记录。

## 操作记录列表

<main id="notice" type='explain'>
  <h4>说明</h4>
  <ul>
  <li>拥有系统角色（system_admin）的用户可管理操作记录。</li>
  <li>操作记录当前永久保留。</li>
  </ul>
</main>
  
1. 在项目协同窗口中，单击 **<UI-TERM key="odc.page.Secure.SafetySpecifications">安全规范</UI-TERM>** > **<UI-TERM key="odc.page.Secure.OperationRecord">操作记录</UI-TERM>**，进入 **<UI-TERM key="odc.page.Secure.OperationRecord">操作记录</UI-TERM>** 页面。

   <img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/423/900.data-security-and-compliance/200.operating-records/1.png" width="900">

   * 通过列表上方的刷新按钮<img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/icon/refresh.jpg" width="20" icon>，可刷新列表信息。

   * 通过 **<UI-TERM key="odc.src.component.Task.AsyncTask.DetailContent.ExecutionTime">执行时间</UI-TERM>** 筛选时间，可支持查看最近 7 天/最近 15 天/最近 30 天/最近半年以及自定义时间段查看。

2. 在操作记录列表中显示并提供如下基本信息。

    |  信息项  |说明|
    |-------|------------|
    | 序号    | 操作记录序号。|
    | 事件类型  | 操作事件类型，包括个人设置、密码管理、连接管理、脚本管理、数据库操作、组织配置、成员管理、资源组管理、模拟数据、数据库变更、导入、导出、权限申请和任务流程等。 单击筛选图标<img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/icon/filter.jpg" width="20" icon>，可筛选事件类型。 |
    | 事件操作  | 显示操作事件信息。 单击筛选图标<img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/icon/filter.jpg" width="20" icon>，可筛选事件操作。 |
    | IP 来源 | 显示 IP 来源。 单击搜索图标<img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/icon/search.jpg" width="20" icon>，可搜索 IP。 |
    | 执行人   | 显示操作执行人。 单击搜索图标<img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/icon/search.jpg" width="20" icon>，可搜索执行人。 |
    | 执行时间  | 显示操作执行的时间。 默认操作记录列表按执行时间排序，最新的执行记录显示在最前。 单击图标<img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/icon/ascending%20and%20descending%20order.jpg" width="20" icon>，可升序或降序。                    |
    | 执行结果  | 显示执行结果，包括 **<UI-TERM key="odc.components.FormRecordExportModal.Successful">成功</UI-TERM>** 或 **<UI-TERM key="odc.component.RecordPopover.components.Failed">失败</UI-TERM>** 。 单击筛选图标<img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/icon/filter.jpg" width="20" icon>，可筛选执行结果。  |
    |操作    | 显示 **<UI-TERM key="odc.components.RecordPage.View">查看</UI-TERM>** 功能键。|

## 查看操作记录

在操作记录列表中，单击 **<UI-TERM key="odc.Project.Database.Operation">操作</UI-TERM>** 项下的 **<UI-TERM key="odc.components.AutoAuthPage.View">查看</UI-TERM>** 按钮，以弹出 **<UI-TERM key="odc.component.RecordPopover.components.RecordDetails">记录详情</UI-TERM>** 面板。

<img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/423/900.data-security-and-compliance/200.operating-records/2.png" width="900">

记录详情中可查看 **<UI-TERM key="odc.component.RecordPopover.components.EventType">事件类型</UI-TERM>**、**<UI-TERM key="odc.components.FormRecordExportModal.EventAction">事件操作</UI-TERM>**、**<UI-TERM key="odc.components.RecordPage.component.IpSource">IP 来源</UI-TERM>**、**<UI-TERM key="odc.components.RecordPage.component.DetailedRules">执行细则</UI-TERM>**、**<UI-TERM key="odc.components.RecordPage.Executor">执行人</UI-TERM>**、**<UI-TERM key="odc.components.TaskTimer.ExecutionTime">执行时间</UI-TERM>** 和 **<UI-TERM key="odc.components.RecordPage.component.ExecutionResult">执行结果</UI-TERM>** 信息。

## 导出操作记录

在操作记录列表左上角，单击导出图标<img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/icon/export.jpg" width="20" icon>，弹出 **<UI-TERM key="odc.components.FormRecordExportModal.ExportOperationRecords">导出操作记录</UI-TERM>** 面板。

导出操作记录列表中显示并提供基本信息如下所示。

<img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/odc/423/900.data-security-and-compliance/200.operating-records/3.png" width="900">


|  信息项   | 说明                     |
|--------|---------------|
| 执行时间范围 | 选择开始日期和结束日期。                              |
| 事件操作   | 筛选需查看的事件操作。                               |
| 所属连接   | 操作所属的数据源名称。 筛选所属数据源（默认选择全部）。 |
| 执行人    | 筛选操作执行人。                                  |
| 执行结果   | 筛选执行结果。                                   |
| 导出格式   | 选择导出格式：Excel 格式 或 CSV 格式。                 |
